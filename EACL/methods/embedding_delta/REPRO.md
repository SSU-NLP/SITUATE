# Embedding Delta (Schneider et al. 2021) — 재현 결과

**판정: 🟡 부분 재현.** 채점기와 저자 제출물 수준에서는 발표 수치가 **정확히** 재현된다.
그러나 저자 코드를 우리가 직접 돌리면 점수가 **저자 제출의 절반**에 그친다. 원인은
아직 특정하지 못했고, 가장 유력했던 가설(sklearn 기본값 드리프트)은 **기각됐다.**

---

## 1. 재현된 것 ✅ — 공식 순위표

`check_official_submission.py` · 저자의 **공식 제출 예측 + 공식 gold**(레포 동봉)를 우리 채점기로 재계산.

| | Track 1 P/R/F1 | Track 2 P/R/F1 |
|---|---|---|
| 논문 Table 1 (Schneider et al. 행) | 0.01 / 0.02 / 0.02 | 0.06 / 0.03 / 0.04 |
| **우리 재계산** | **0.01 / 0.02 / 0.02** | **0.06 / 0.03 / 0.04** |

이걸 맞추려면 논문에 안 적힌 세 가지를 알아내야 했다 — `../README.md` §2 참조:
표제 "Micro avg." 의 실제 정의(문서별 micro 의 평균), 전이 타입까지 맞아야 하는 채점,
공식 코드의 라벨 배정 순서 의존 버그.

## 2. 재현되지 않은 것 🟡 — 우리가 직접 돌린 결과

`run_test2.py` / `run_test2_sklearn024.py` · 저자 코드 `add_scenes_to_json` 을 **무수정 호출**,
저자 동봉 SVM(`code/svm.pickle`) 그대로, STSS-Test-2 2편.

| 조건 | 2025 gold F1 | 2021 gold F1 |
|---|---|---|
| 저자 공식 제출 (기준점) | **0.0355** | **0.0567** |
| 우리 재실행 · sklearn 1.9 기본값 (n=5) | 0.0181 ± 0.0034 | 0.0271 ± 0.0037 |
| 우리 재실행 · sklearn 0.24 기본값 복원 (n=5) | 0.0203 ± 0.0072 | 0.0265 ± 0.0048 |

예측 경계 수도 적다: 우리 87~92 / 103~109개 vs 저자 112 / 121개.

### 🔴 sklearn 가설은 기각됐다
`MiniBatchKMeans` 기본값이 발표 이후 바뀐 것을 확인했고(batch_size 100→1024, n_init 3→auto),
저자 코드가 그 값들을 기본값에 맡기므로 유력한 용의자였다. 0.24.2 값으로 복원해 5회 돌린
결과는 **0.0203 ± 0.0072 로 사실상 변화 없음**(기존 0.0181 ± 0.0034 와 구간이 겹친다).
격차 −0.015 는 그대로다. **이 가설은 틀렸다.**

### 남은 용의자 (미검정)
1. **spaCy 모델 버전** — 저자 `requirements.txt` 는 버전을 고정하지 않았다. 우리는
   `de_core_news_lg==3.8.0`, 2021년은 3.0~3.1 계열. 토큰 벡터가 바뀌면 코드북이 통째로 바뀐다.
   과거 모델 휠이 아직 배포돼 있으므로 검정 가능하다.
2. **문장 분할이 다르다** — 저자는 2021 공식 입력 JSON 의 `sentences` 를 받았고, 우리는
   2025 standoff 의 문장 경계를 쓴다. 창 크기가 25**문장**이라 분할이 달라지면 신호가 달라진다.
   2021 입력 JSON 은 저작권 자료라 우리에게 없다.
3. **SVM 피클의 sklearn 버전 불일치** — 0.24.2 산 피클을 1.9.0 에서 언피클했다. 예측이
   퇴화하지는 않았지만(구간 90여 개 중 Scene 82~86) 값이 미묘하게 달라질 여지는 남는다.

## 3. 이 방법의 성질 (재현과 별개로 기록할 것)

- **비결정적이다.** `MiniBatchKMeans` 에 `random_state` 가 없어 실행마다 결과가 흔들린다.
  실측 표준편차 F1 0.003~0.007. 단일 실행 수치를 보고하면 안 된다.
- **저자 자신의 점수가 매우 낮다.** STSS 2021 5개 팀 중 최하위(Track1 F1 0.02).
  "재현했다/못 했다"의 차이가 0.02~0.06 구간의 미세한 차이라 해석에 주의가 필요하다.

## 5. 비교 기준점을 왜 따로 만들었나

발표값 0.04 는 **2021 gold · 문자 오프셋** 조건이고 우리 예측은 **2025 문장 격자**에 찍힌다.
2021 gold 는 장면 시작을 문장 앞 공백에 찍어(드리프트 0/+1/+31자) 그대로 채점하면 전부
오답이 된다. 그래서 저자의 공식 제출 예측을 같은 격자에 올린 값을 기준점으로 삼았다
(`../common/verify_grid.py`).

🔴 **문장 격자 스냅은 점수를 올린다**(저자 예측 기준 F1 0.0446 → 0.0567). 근접 예측을
정답으로 바꿔주기 때문이다. 그러므로 격자 위 수치를 발표값과 나란히 놓으면 안 된다.
