# Figure 서식 기준

기준 이미지 `좋은figure예시.jpg`. 코드로 고정한 것이 `GoodFigureExample.py` — 새 figure 는 이 모듈을
import 하거나 복사해서 쓴다.

## 파일명·저장

CLAUDE.md 규약: `EACL/figures/figure_<번호>_<제목>.{pdf,png}`

- 번호는 `01`부터 2자리 zero-pad. 새 figure = 가장 작은 미사용 번호, 수정·재생성 = 번호 유지
- 제목은 snake_case 핵심어
- **PDF + PNG 둘 다** 저장, 300dpi, `pdf.fonttype=42`(폰트 임베드)
- 알파벳 체계(`figure_A_*`)와 `outputs/figures/` 는 2026-08-02 폐기

## 색

예시 이미지 픽셀에서 추출한 값.

| 역할 | HEX | 쓰임 |
|---|---|---|
| 주 계열 | `#c1392b` | 첫 번째 계열 |
| 부 계열 | `#5d9383` | 두 번째 계열 · 오른쪽 축 |
| 3번째 계열 | `#b69fca` | |
| 텍스트·왼쪽 축·x축 | `#000000` | |
| 보조 텍스트 | `#7a7a7a` | 각주·주석 |
| 기준선 | `#d9d9d9` | 점선 reference line |

계열 색은 **고정 순서**로 배정한다. 계열이 줄어도 살아남은 계열의 색을 바꾸지 않는다.

## 글씨

| 요소 | pt |
|---|---|
| 기본 | 14 |
| 축 라벨 | 15 |
| 눈금 라벨 | 14 |
| 범례 | 14 |

폰트 `DejaVu Sans`. ⚠️ 이 환경에 한글 폰트가 없다 — **그림 안 텍스트는 영문으로만** 쓴다.

## 축

- **위쪽 spine 제거.** 격자 없음. 제목 없음(캡션이 대신한다)
- 눈금은 바깥 방향, 길이 5, 두께 1.3
- **눈금이 축 끝 모서리에 붙지 않게** 축 범위를 데이터보다 넓게 잡는다 (`pad_xlim`)
- **이중 y축**을 쓸 때는 각 축의 spine·눈금·눈금라벨·축라벨을 해당 계열 색으로 칠해
  곡선과 축을 색으로 잇는다 (`color_axis`). 이때 반대쪽 spine 은 숨긴다
- 단위가 다른 두 지표를 한 축에 얹지 않는다 — 축을 나누거나 그림을 나눈다

## 범례

- 그림 **아래 중앙**, **테두리 없음**, 한 항목당 한 줄(`ncol=1`)
- 마커 왼쪽 + 텍스트 오른쪽, 항목 간격 넉넉히(`labelspacing≈0.75`)
- 계열이 둘뿐이고 축 라벨로 이름을 표시할 수 있으면 **범례를 생략**한다
  (figure_01 이 그 방식 — 좌우 축 라벨이 계열 이름을 대신한다)

## 크기

기본 `figsize=(7.2, 5.4)`. 예시 이미지와 같은 비율.

## 예시

`../../scripts/eacl_phase1/plot_cap_sweep.py` — figure_01 생성 스크립트. 이중 축, 범례 생략,
축 색 연결, 모서리 여백을 모두 이 기준대로 쓴 참고 구현이다.
