# HANDOFF 09 — 인과 축 재조작화: 동결 규칙 교체 후보 검정 (2026-07-31)

## 문제 정의

**동결 인과 축 `reset_causality = (event_type 변화) ∨ (b.aspect == inceptive)` 이 무작위와 구별되지
않는다.** 5축 중 유일하게 그렇다. 이 축을 무엇으로 바꿔야 하는가, 바꾸면 학습된 M5 가 나아지는가.

**성공 기준 (사전등록, 결과 보기 전 고정)**
- 후보 축이 **밀도 매칭 무작위 대조**를 유의하게 넘을 것 (동결은 +0.0116 = 사실상 못 넘음)
- 그 축으로 앵커 재라벨 후 **M5 재학습** 시 dev-3 deployable Score 가 현행 W3(0.3963)를 넘을 것
- dev-3 절대 Score 는 성능으로 인용하지 않는다 — Δ·방향만. 시험지 미개봉 유지

## 배경 — 왜 이 문제가 열렸나 (2026-07-31 감사)

| 발견 | 근거 |
|---|---|
| 인과 축의 실체 = **event_type 범주 교대 탐지기** | 앵커 전량에서 `event_type` 변화와 일치도 **0.9798** |
| 인과는 판별자가 아니라 **상시 참인 게이트** | `P(경계\|인과=1) 0.090` 대 `P(경계\|인과=0) 0.0078`, 경계의 **96.3%** 에서 켜짐 |
| 실질 규칙은 **"인과 제외 4축 ≥2"** | 5축 ≥3 과 Jaccard **0.757** · 일치율 **0.979** |
| 축 단독 Score 가 **무경계 하한보다 낮다** | 0.2148 < 0.2790 (예측 687개 = 10.4배 과분절) |
| 밀도 통제 후 기여 ≈ 0 | Δ무작위 **+0.0116** (5축 중 최저, 의도 +0.0171 이 그다음) |
| 조작화 8건 전부 실패 이력 | `EACL/phase0-decisions-and-runs.md` D-B9/D-B13/D-B21/D-B22/D-B23 |

전 실험 REPORT: `outputs/experiments/2026-07-31_{anchor_axis_audit, causal_cohesion_veto,
causality_bakeoff, axis_calibration}/`
