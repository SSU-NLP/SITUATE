# gold-swap 랭킹보존 검사 (D-M11 ②)

**Date:** 2026-07-16 · **판정:** 사전 고정 기준상 **역전** — M3−M1이 gold 교체에 부서짐(monkey에서 +0.051→−0.005). **단 headline인 M3−B1은 3/3 보존.** 밀도 진단(D-M11 ⑥)과 독립적으로 같은 결론에 수렴.
**스크립트:** `scripts/eacl_phase0/dev_goldswap.py` · raw run 캐시 `outputs/eacl_phase0/dev_b3ref/` (재지불 방지) · 산출 `goldswap.json` · `goldswap_table.txt`

## 1. 실험 setup

- **질문.** Tier2 주장 "M3 > M1/B1 (B3-gold 기준)"이 "M3 > M1/B1 (인간 기준)"의 대리로 성립하는가 = **같은 문서에서 gold만 인간→B3로 교체해도 pairwise 부호가 보존되는가.** (기존 dev vs Tier2 비교는 gold 출처와 문서가 동시에 달라 교란.)
- **데이터.** dev 인간 gold 3편(pieman/tunnel/monkey michelmann, author-filtered).
- **방법·동결 knob.** M3(count≥t\*=3) · M1(μ+1.0σ) · B1(newsent_max, μ+0.75σ). **예측 재생성 없이 동일 예측을 두 reference로 채점.**
- **reference 2벌.** (a) 인간 gold (b) **B3 reference = Tier2와 동일 프로토콜**(GPT-4.1 · B2 프롬프트 verbatim · temp 0 × **20회** · B3 top-n 합의).
- **🔒 판정 기준(D-M11 ② 사전 고정).** 1차 = M3−M1, M3−B1 부호. 보존=둘 다 3/3 동일 / 역전=하나라도 반전 / 불충분=부호 같으나 불일치(3편뿐이라 모호시 기본값).
- API: dev 3편 × 20 rep ≈ 실 지출($2~3 규모). raw run 디스크 캐시 → 재채점은 `--reuse`로 API 0.

## 3. 해석

### 3.1 두 독립 실험이 수렴한다

| | M3 vs M1 | M3 vs B1 (headline) |
|---|---|---|
| **밀도 진단(⑥)** | 작동점 정합 효과(|log ratio| 0.53 vs 1.47); AUC 0.717 vs 0.680(격차 작음) | AUC 0.717 vs 0.558(near-chance); 임계 제거해도 큼 |
| **gold-swap(②)** | **monkey에서 부호 반전(+0.051→−0.005)** | **3/3 보존** |

**같은 결론:** M3−M1은 표현 우위가 아니라 임계규칙(작동점) 효과라 **취약**하고 gold 교체에 부서진다. M3−B1(EISM 다축 vs EST 스칼라 서프라이즈 = **실제 H1**)은 **두 검사 모두 통과**.

### 3.2 B3는 인간 gold와 교환 불가

B3 합의는 안정적(split-half F1 높음)이나 **인간보다 계통적으로 희소**(밀도 2~4.5×)하고 **랭킹을 바꾼다**(monkey M3−M1 반전). ⇒ **B3 gold는 "신뢰할 수 있는, 그러나 인간 사건경계와 다른 것"의 측정.** Tier2 절대 Score를 인간 성능으로 해석 불가(D-M11 ③ 확증).

### 3.3 monkey에서 왜 반전됐나

monkey는 journalism(경계조건 ①). 인간 gold(밀도 0.074)에서 M3가 M1을 근소하게 앞서나(+0.051), B3 gold(밀도 0.034)로 바꾸면 M1이 근소하게 앞선다(−0.005 ≈ 무승부). **±0.005는 사실상 tie** — 즉 monkey의 M3−M1은 애초에 gold 출처에 좌우되는 허약한 격차였다. 밀도 진단이 예측한 "작동점 의존성"의 직접 증거.

## 4. 판정

- **통합 "held-out 승리" 주장 = 철회** (사전 고정 규칙: M3−M1 반전 → 역전).
- **headline M3 > B1 = 유지** — gold-swap 3/3 보존 + AUC 0.717 vs 0.558. **논문의 중심 대조(EISM vs EST)는 살아남는다.** 단 (a) n=3 dev (b) B3 reference 지위(D-M11 ③) (c) Tier2 청정 5편·Tier3 확인 전까지 인간 일반화 주장 불가.
- **M3 > M1 주장 = 폐기** — 표현 우위로 인용 금지(밀도+gold-swap 이중 반증). 허용 표현 = "M3의 경계수 자가결정 규칙이 M1의 고정분위수 규칙보다 참조 밀도에 적응적."
- **B3 프로토콜 자체 = 유효** — 합의 안정성 확증(split-half). D-M9 설계 건재. 문제는 B3-인간 교환가능성이지 B3 내부 신뢰도가 아님.

## 5. 한계 / 검증 미해결

- **n=3 dev.** monkey 반전이 −0.005(tie)라 "깨끗한 M1 승리"는 아니나, 사전 고정 규칙상 부호 반전은 반전 — 사후 완화 금지. 어느 쪽이든 M3−M1은 "보존" 아님.
- **M3−B1 보존도 n=3 한계** — 확인적 근거는 Tier2 청정 5편 + Tier3.
- **B3 계통 희소성의 원인 미규명** — 프롬프트("large events")가 인간보다 coarse한 분절을 유도하는지, GPT-4.1 특성인지 미분리.
- gold-swap은 **랭킹 보존**만 검사 — B3 절대 품질(인간 대비 정확도)은 인간 간 일치도(측정 상한) 부재로 여전히 미판정.
- 예측은 동결 설정 재사용(재생성 0)이라 M3/M1/B1 예측 자체는 기존과 동일 — 검사는 순수하게 gold 축만 변화.
