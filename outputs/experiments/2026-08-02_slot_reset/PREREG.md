## 0. 왜 하나

`factored_slot.py:52` 가 **미구현**으로 명시해 둔 항목이다:

> ⚠️ ③ 경계에서의 상태 리셋(event switching)은 여전히 미구현이다.

현행 슬롯 상태 $s_t^{(k)}$ 는 문서 시작부터 끝까지 리셋 없이 누적된다. 설계문서와 SEM 계승 관점에서
사건이 바뀌면 상태가 전환돼야 하므로 이건 결손이다. 논문에 **"미구현"** 으로 남기는 것과
**"시험 후 기각"** 으로 남기는 것은 강도가 다르다 — 후자를 만든다.

관련 선행: D-B62 의 ψ(에피소드 요약)는 **슬롯 옆에 붙인 별도 벡터**를 경계에서 리셋한 것이고,
슬롯 상태 자체를 리셋한 적은 없다. ψ 는 전 평가셋에서 무효였고 **과분절을 키웠다**(적응임계
BOR 2.39 → 2.50). 그래서 이번 기대값은 낮다 — 그래도 설계문서가 요구하는 항목이라 시험한다.

## 1. 구현 — 무엇을 리셋하나

`slot_reset="hard"`: 전이 $j$ 가 경계면 슬롯 메모리를 **key 로 되돌린다**($s^{(k)} \leftarrow q_k$).

🔴 **리셋은 한 문장 지연된다.** 전이 $j$ 의 경계 판정 자체가 $s_{j+1}$ 을 필요로 하므로,
$s_{j+1}$ 은 연속 갱신으로 만들고 리셋은 $s_{j+2}$ 를 만들 때의 이전 상태에 적용한다.
순환을 피하는 유일한 인과적 배치이며, **학습·추론 경로가 같은 지연을 쓴다.**

| | 리셋 신호 |
|---|---|
| 학습 | 앵커 경계(`count ≥ t*=3`) + **teacher reset dropout 0.3** (ψ 와 같은 처방) |
| 추론 | **자기 예측 경계** `Σ_k 1[p_k > 0.5] ≥ t*` — `change_probs_slot_rollout`. 앵커·gold·미래 미사용 |

지표는 **J_anchor** (앵커 val 5-fold OOF deployable Score) 하나. 모델 **구조** 선택이므로 앵커에서
