**데이터.** 직전 세대가 디스크에 남아 있고 겹친다 = 이미 확보된 독립 2차 draw.

**⚠️ 측정되는 것의 정확한 정체.** 두 세대는 TP 차수와 prefix caching 이 다르다. 따라서 관측 불일치 =
(재실행 샘플링 지터) + (서빙 설정 변경 효과) 이며 **k=1 변동의 상한(upper bound)** 이다. 순수 k 지터는
이보다 작다. 이 caveat 는 측정 전 스크립트 docstring 에 명시했다.

**지표.** 축별 일치율·Cohen κ·McNemar 비대칭 / count 일치율·평균 |Δcount| / 경계 Jaccard /
**headline = S_self** = 공식 채점기 `hi_ontop.dts_scoring.score_dialogues` 로 두 세대를 서로 채점한
대칭 평균(끝-turn 규약, deployable). 기존 `noise_floor_run2run.py`(D-B11 후속)와 동일한 정의.

**사전선언 판정 기준 (측정 전 확정).**

| S_self | 해석 |
|---|---|
| ≥ 0.90 | 작음. k=1 로 1차 패스 진행. 해석 폭 = (1 − S_self) |
| 0.75 ~ 0.90 | 중간. k=1 진행하되 M5−M4 ΔScore 가 (1 − S_self) 미만이면 "가설 지지" 금지 |
| < 0.75 | 큼. 1차 패스 결과는 **방향성만**. 확정 패스에서 다중 draw 필수 |

무작위 vs 계통적 = (a) 5축 전부 McNemar 비대칭 < 0.10 **그리고** (b) 문서별 불일치 과분산비 < 1.5 를
모두 만족하면 무작위, 하나라도 위반하면 계통적.

## 3. 해석

**축 라벨은 생각보다 안정적인데, 경계는 불안정하다.** 전이의 68.9%가 5축 전부 일치하고 축별 κ 는
0.54~0.91 이다. 그런데 경계 Jaccard 는 0.42 로 무너진다. 원인은 **정수 임계 t\*=3 의 증폭**이다 —
경계 불일치의 **77.7%가 count 2↔3**, 즉 *단 한 축이 임계 바로 옆에서 뒤집힌 것*이다. 경계율이
6.4% 로 희소하므로 대부분의 경계 후보가 임계에 딱 붙어 있고, 한 축의 flip 이 곧바로 경계 생성/소멸이
된다. t\* 를 올릴수록(=경계가 희소할수록) Jaccard 가 단조 악화하는 것(0.64 → 0.42 → 0.29)이 이
메커니즘의 직접 증거다.

이는 새 발견이 아니라 **이미 문서화된 결함의 정량화**다 — `method-registry.md` §5 *"t\* 작동점 결함:
정수 임계값이 문서 길이에 무관하게 적용되어 긴 문서에서 과예측. M5 의 sticky-CRP 지속성 사전(κ)이
이를 원리적으로 해결할 것으로 예상 — 단 이는 검증 대상이지 보장이 아님."*

**"계통적" 판정은 절반이 설계상 예정된 것이다.** 5축 전부에서 c > b(B가 더 많이 발화)라는 **일관된
방향성**은 무작위 지터가 아니라 **설정 변경(TP 2→1, prefix off→on)의 서명**이다. 두 세대를 일부러
다른 조건에서 비교했으므로 이 성분은 예상됐고 측정 전에 caveat 로 적어두었다. 반면 **과분산비 7.15
(문서별 군집)는 설정 변경으로 설명되지 않는다** — 전역적 설정 이동은 모든 문서의 불일치율을 고르게
올릴 뿐이다. 즉 **문서에 따라 앵커 안정성이 크게 다르다**는 것은 실제 신호이고, 문서별 S_self
10퍼센타일 0.481 vs 90퍼센타일 0.825 가 같은 이야기를 한다.

**time 축의 비대칭 0.236 은 절대량이 작다.** b=2,874 vs c=4,654 로 비율은 크지만 발화율 자체가
0.02 라 전체 count 에 미치는 영향은 제한적이다. κ 는 0.910 으로 5축 중 최고다.

**intentionality κ 0.540 이 5축 최저**로, 이 축이 가장 불안정하다. D-M13⑥ 이 goal 축을 3편 공통
최저(F1 0.38)로 지목한 것과 방향이 같다.

## 4. 판정

**사전선언 기준 대조 = FAIL.** S_self = **0.6585 < 0.75** → 선언한 밴드에 따라
**"1차 패스 결과는 방향성만. 확정 패스에서 다중 draw 필수."**

**기준을 고치지 않는다.** 결과를 본 뒤 임계를 낮추거나 지표를 바꾸면 D-M5(선택 오염) 재현이다.
FAIL 로 기록하고, 아래에 "알고도 진행"의 근거만 적는다.

**알고도 1차 패스를 진행하는 이유 (사용자 결정 D-B16 + 아래 사후 관찰):**

1. **이 수치는 상한이다.** 설정 변경 성분(5축 전부 c > b)이 포함돼 있어 순수 k 지터는 이보다 작다.
   얼마나 작은지는 **미측정** — 동일 조건 재라벨이 없기 때문이다.
2. **🔴 사후 관찰(post-hoc, 기준 변경 아님 — 판정은 위의 FAIL 그대로다):** 내가 사전선언한 S_self 는
   **M3 가 만든 *경계*의 재현성**을 잰다. 그런데 M4/M5 의 학습 앵커는 경계가 아니라 **축별 reset 라벨
   5개**(κ 0.54~0.91, 전이의 68.9%가 완전일치)다. 두 대상은 다르며, 임계 증폭(77.7%)은 학습 타깃에
   적용되지 않는다. 또한 M4 와 M5 는 **동일한 노이즈 라벨**로 학습되므로 M5−M4 는 공통 타깃에 대한
   **짝지은 비교**다. ⇒ 사전선언한 지표가 이 패스의 실제 위험을 과대평가할 가능성이 있다. **단 이것은
   측정 후에 떠오른 생각이므로 판정을 뒤집는 데 쓰지 않는다.** 확정 패스에서 *학습 타깃 기준의*
   안정성 지표를 **미리** 선언해 다시 재야 한다.
3. 목적이 "가설이 얼추 맞는지"이지 성능 주장이 아니다(D-B16).

**⇒ 3단계(M4/M5) 결과 보고 규약 (이 REPORT 로 확정):**
- M5−M4 ΔScore 를 **"가설 지지"라고 부르지 않는다.** 부호와 방향만 보고한다.
- dev-3 절대 Score 를 **성능으로 인용하지 않는다.**
- 모든 표에 "앵커 k=1, S_self 0.659(상한), 탐색적" caveat 를 단다.
- 확정 주장은 확정 패스에서만.

## 5. 한계 / 검증 미해결

- **동일 조건 반복이 없다.** 순수 k 지터를 분리하려면 TP·prefix 를 고정한 채 같은 문서를 2회 이상
  라벨해야 한다. 본 측정은 조건이 섞인 상한뿐이고, **상한과 실제의 간격은 미측정**이다.
  확정 패스 전에 소규모(예: 300편) 동일 조건 k=3 재라벨로 좁히는 것이 다음 후보.
- **사전선언 지표의 적합성 문제(§4-2).** S_self 는 경계 재현성이고 학습 타깃은 축별 라벨이다.
  기준을 사후 교체하지 않았으나, **다음 사전등록에서는 학습 타깃 기준 지표를 함께 선언해야 한다.**
- **t\* 진단표(§2.5)는 진단 전용.** t\*=2 의 Jaccard 0.643 이 더 높다는 것은 작동점 재선택의 근거가
  **아니다** — t\*=3 은 dev argmax-Score 로 동결됐고(🔒 동결 갱신 07-13), 재현성만 보고 작동점을 고르면
  성능 기준을 재현성 기준으로 몰래 바꾸는 것이 된다. **t\*=3 동결 유지.**
- **문서별 군집(과분산 7.15)의 원인 미규명.** 어떤 문서가 불안정한지(장르? 대사 비율? 인물 수?
  폭주 근접?)를 안 봤다. `per_doc.npz` 에 문서별 S_self·Jaccard·전이수·불일치율이 저장돼 있어
  사후 분석은 가능하다.
- **gold 없음.** 두 세대의 *일치*만 잰 것이지 어느 쪽이 *맞는지*가 아니다. 두 draw 가 같은 방향으로
  틀렸을 가능성은 이 측정으로 배제되지 않는다.
- **조인 손실.** A 7,991편 중 7,920편만 겹친다(71편 미포함). B 의 10,598편 중 2,678편은 2차 draw 가
  없어 이 측정의 표본 밖이다 — 신규 확장분(D-40)이라 계통적으로 다를 수 있다.
