## 공통 배경

세 후보 모두 **동결 인과 축**을 대체하는 후보다. 동결 규칙:

```python
def reset_causality(a, b):                     # a = 문장 t-1, b = 문장 t
    return int(a["event_type"] != b["event_type"] or b["aspect"] == "inceptive")
```
- 앵커 발화율 **0.6950** · dev-3 축 단독 Score **0.2148**(무경계 하한 0.2790보다 낮음)
- 감사 결과 실체 = **event_type 범주 교대 탐지기**(일치도 0.9798), 경계의 96.3%에서 상시 켜짐

## F3 — `b.aspect == completive`

| 항목 | 내용 |
|---|---|
| **구성개념** | 문장 t 가 **완료된 사건**을 기술하는가. 완료상이 사건 경계로 지각된다는 문헌 예측 |
| **라벨 출처** | 현행 causality Stage-2 가 이미 뽑는 `aspect` ∈ {inceptive, ongoing, completive} |
| **규칙** | `reset = (b.aspect == "completive")` — **문장 b 단독 판정** |
| **dev-3 실측** | Score **0.3555** ±0.0097 · 발화율 0.071 · 예측 **66개(gold 66과 동일)** · lift 2.47 |
| **앵커 발화율** | **0.062** (20편 표본: ongoing 0.855 / inceptive 0.083 / completive 0.062) |
| **1만편 준비** | 🟢 **API 0.** `phase1_all_v31/*/causality_states.jsonl` 에 aspect 가 이미 있다. reset 컬럼만 재계산(수 분) |
| **이론적 지위** | 문헌이 **사전에 예측한 방향**. 동결 규칙은 정확히 반대(inceptive)를 쓰고 있었다 |
| **약점** | ① **b 단독 = 전이 함수가 아니다.** 시간 축과 같은 결함이며, M5 의 축별 dynamics 가 이 축에서 학습할 것이 없다. ② dev-3 에서 오늘 오전에 이미 열람(맹검 아님) |

## F12 — 인과 사슬 strict (D-B23)

| 항목 | 내용 |
|---|---|
| **구성개념** | **의도와 무관한 인과 사슬**(A 가 B 를 야기). goals(의도·목적)와 조작적으로 구분 |
| **라벨 출처** | 🔴 **별도 축.** Stage-1 = 문서별 인과 사슬 **닫힌 목록** 열거 → Stage-2 = 문장마다 소속 사슬 배정(`none` 허용) |
| **규칙** | `reset = (chain(a) != chain(b)) and "none" not in (chain(a), chain(b))` — 양쪽 다 사슬 안에 있고 서로 다른 사슬일 때만 |
| **dev-3 실측** | Score **0.3556** · 발화율 0.050 · 예측 **31개(0.47배)** · lift **3.35 (최고)** |
| **앵커 발화율** | ❌ **모름 — 앵커에 라벨이 없다** |
| **1만편 준비** | 🔴 **전량 신규 추출 필요.** ① `causalchain` 은 `llm_s5_states.py` 의 축이 아니다(`EXPERIMENT_AXES = ("chainrole",)` 뿐) — 프롬프트가 독립 러너 `causal_chain_redundancy_diag.py` 에만 있다. ② Stage-1(문서당 1회 × 10,598) + Stage-2(문장 2.78M) 신규 호출. 5축 전량 런이 20×A100 3h23m 이었으므로 **1축 ≈ 13 GPU-시간**, 보유 2장이면 **6~7시간** + 샤딩·재개 인프라 이식 |
| **이론적 지위** | **8건 중 EISM 인과 지표(사건 간 관계)에 가장 가까운 조작화.** dev-3 에서 비의도적 인과를 실제로 포착(`dean_aggression → pie_attack`) |
| **약점** | ① **D-B23 에서 명시적으로 종결된 트랙**("정식 축 후보에서 causality 탐색 종료, 라벨 재정의·표본 확장 하지 않는다") — 재개는 그 결정을 뒤집는 것 ② dev-3 에서 `none` 율 **0.83~0.93** = 관계형 구성개념과 문장 단독 판정의 구조적 불일치 ③ 예측 31개는 gold 66 의 **0.47배 = 과소분절** ④ 앵커 발화율 미지 — 문어 픽션에서 사슬 밀도가 어떨지 모른다 |

## 학습 실험 설계 (실행 전 확정 필요 사항)

**바뀌는 것은 앵커의 `causality` 열 하나뿐**이다. 나머지 4축·인코더·아키텍처·학습 HP 전부 동결.

1. 앵커 `reset_matrix` 재계산 → `build_anchor_dataset.py` 재실행 → M5 학습(seed 0/1/2).
   조건 네임스페이스 분리 필수(`_aspcomp` / `_nonong` / `_chainstrict`). 기존 산출 무손상 보존.
2. **경계 규칙**: 축 발화율이 0.695 → 0.06~0.15 로 바뀌면 앵커 경계율(현행 0.0649)도 바뀐다.
   - **주 = 적응 임계**(`online_nf`, c=1.0). 🔒 c 의 출처가 SuperDialseg 공식 test 라
     **앵커에서도 dev-3 에서도 아무것도 고르지 않는다.** 조건 간 공정 비교가 성립한다.
   - 보조 = 문서 내 분위수. r 은 조건별 앵커 경계율에서 **정의상 계산**(점수로 고르는 것이 아님).
3. 판정 = dev-3 deployable Score, 3시드 평균±SD, **문서별 병기**. 기준선 = 현행 M5 W3(0.3963).
4. 🔴 dev-3 는 이미 선택압이 누적됐다(9회 + 오늘). 여기서 나온 수치는 **선택 결과**이며
   **성능으로 인용하지 않는다.** 확인은 봉인 시험지 1회 개봉뿐이다.

**권고 순서:** F3 → F4 를 먼저 돌린다(둘 다 API 0, 재계산 + 학습만). F12 는 결과를 본 뒤
**별도 결정**으로 다룬다 — 6~7시간 라벨링과 D-B23 종결 번복이 걸려 있어 같은 층위의 선택이 아니다.
