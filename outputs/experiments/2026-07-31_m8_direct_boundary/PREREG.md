# 사전등록 — 경계-직행 베이스라인 (M8-DirectBoundary)

**작성 시각: 2026-07-31 (KST), 결과를 보기 전.** 이 파일은 실행 전에 쓰고 이후 수정하지 않는다.
(근거 규칙: [[no-postresult-criterion-change]] · CLAUDE.md "결과 본 뒤 기준 변경 금지")

## 1. 왜 이 베이스라인이 필요한가

현재 논문에는 **5축 구조의 기여를 분리하는 베이스라인이 없다.**
M4-MonoAnchor 는 "단일 잠재 대 5슬롯"을 보지만, 둘 다 **축별 리셋 라벨로 학습**하고
**축별 확률의 합**을 신호로 쓴다. 즉 M4 도 5축 라벨을 소비한다.

빠진 대조군 = **동결 인코더 + 이진 경계 헤드 직행 모델**.
5축을 거치지 않고 앵커에서 유도된 **경계 라벨 하나만**(동시 리셋 ≥ 3) 학습한다.
경계 라벨은 앵커에서 코드로 유도되므로 추가 라벨링 비용이 0이고, 지금 당장 학습 가능하다.

리뷰 관점: 이 베이스라인이 M5 와 동률이면 **5축 분해의 예측적 기여는 0**이고,
남는 주장은 해석 가능성(어느 축이 리셋됐는지 읽힘)뿐이다.

## 2. 방법 (M8-DirectBoundary)

| 구성요소 | 사양 |
|---|---|
| 인코더 | `paraphrase-multilingual-mpnet-base-v2` 768D L2정규화 **동결** (M1~M7 · 전 베이스라인 공통) |
| 입력 (주 변종 `pair`) | `[z_{t-1}, z_t, z_t − z_{t-1}, z_{t-1} ⊙ z_t]` = 3072D |
| 입력 (부 변종 `ctx`) | 위 + `z_t − c_{t-1}` (c = 과거 문장 누적평균, **과거만** = 온라인 적법) = 3840D |
| 헤드 | Linear(D→256) → GELU → Dropout 0.4 → Linear(256→1). 은닉 1층 |
| 출력 | 경계 확률 1개. **축 없음 · dynamics 없음 · 상태 없음** |
| 학습 라벨 | 앵커의 **동시 리셋 ≥ t\*=3** 1개 (축별 5라벨 미사용) |
| 손실 | plain BCE, pos_weight = 1 (W3 결정 승계 — 확률 왜곡 금지) |
| 최적화 | Adam lr 3e-4, batch 8192, 8 epoch, seed 0/1/2 |
| 데이터 | phase1 앵커 10,598편, 분할 seed 20260728 · val 5% — **M4/M5 와 동일 분할** |

**하이퍼파라미터 탐색 없음.** lr·epoch·dropout·pos_weight 는 전부 M5 값을 그대로 가져온다.
dev-3 로 고르는 것은 아무것도 없다(모델 선택도 없음 — 마지막 epoch 사용).

## 3. 평가 (전부 deployable · gold 경계 개수 미사용)

- **주 지표 = DTS Score** (`hi_ontop.dts_scoring.score_dialogues`), AUC 는 보조.
- 데이터 = **dev-3**(pieman/tunnel/monkey). 🔒 **봉인 시험지 미개봉.**
- 임계 규칙 2개, 둘 다 M5 와 **완전히 동일한 함수**로 계산한다:
  1. **적응임계** `online_nf`, c = 1.0, warmup 5 (D-B39 동결값, 출처 = SuperDialseg 공식 test)
  2. **문서 내 고정분위수** r = 0.0642 (🔒 D-B30 앵커 val 동결값)
- 비교 대상은 **같은 스크립트로 그 자리에서 재평가**한다: M5 W3 seed0/1/2, M4 seed0/1/2.
  (문서에 적힌 수치를 옮겨 적지 않는다.)

## 4. 판정 기준 — **실행 전에 고정**

Δ = (M5 평균 Score) − (M8 최고 변종 평균 Score), 적응임계·고정분위수 각각에 대해.
M8 은 **우리 주장을 위협하도록** 두 변종 중 **높은 쪽**을 대표값으로 쓴다(자기유리 선택 금지).

| 조건 | 판정 | 논문에 쓸 문장 |
|---|---|---|
| Δ ≤ +0.06 (= 앵커 재현성 노이즈 하한, D-B15 0.87) | **5축 분해의 예측적 기여 없음** | 5축은 예측 성능이 아니라 **해석 가능성**으로만 정당화한다. M8 을 본문 표에 싣는다 |
| Δ > +0.06, 두 임계 규칙 모두 | **5축 분해가 예측적으로 기여** | M8 을 애블레이션 표의 하한으로 싣는다 |
| 두 규칙의 부호가 갈림 | **결론 없음(노이즈)** | 두 값을 다 싣고 "임계 규칙 상호작용"으로 적는다 |

- **어느 결과가 나와도 M8 은 논문에 싣는다.** 결과를 보고 싣고 말고를 정하지 않는다.
- dev-3 **절대 Score 는 성능으로 인용하지 않는다 — Δ·방향만.**
- 3편·3시드는 표본이 작다. Δ 는 시드 SD 와 함께 보고한다.

## 5. 이 실험이 답하지 못하는 것 (미리 적는다)

- **해석 가능성은 측정하지 않는다.** M8 이 이겨도 "어느 축이 리셋됐는가"는 M8 에서 읽을 수 없다.
- 앵커 라벨 자기일치도 0.659 가 M5·M8 **양쪽의 공통 상한**이다.
- M8 은 상태를 안 갖는다(pair 변종). 온라인이지만 **스트리밍 상태 모델이 아니다** —
  "구조 없는 하한"이라는 지위가 그 때문에 오히려 강해진다.
