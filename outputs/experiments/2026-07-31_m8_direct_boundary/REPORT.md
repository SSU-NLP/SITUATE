## 1. 실험 setup

### 1.1 목적
"5축 구조의 기여를 분리하는 베이스라인이 없다"를 닫는다. M4-MonoAnchor 는 **단일 잠재 대 5슬롯**을
보지만 **M4 도 축별 리셋 라벨로 학습하고 축별 확률의 합을 신호로 쓴다.** 5축을 아예 거치지 않는
대조군이 없었다.

### 1.2 방법 (M8-DirectBoundary)

| 구성요소 | 사양 |
|---|---|
| 인코더 | `paraphrase-multilingual-mpnet-base-v2` 768D L2정규화 **동결** (M1~M7·전 베이스라인 공통) |
| 입력 `pair`(주) | `[z_{t−1}, z_t, z_t − z_{t−1}, z_{t−1} ⊙ z_t]` 3072D → 파라미터 **786,945** |
| 입력 `ctx`(부) | 위 + `z_t − c_{t−1}`(c = 과거 누적평균, **과거만** = 온라인 적법) 3840D → **983,553** |
| 헤드 | Linear(D→256) → GELU → Dropout 0.4 → Linear(256→1). **축 없음 · dynamics 없음 · 상태 없음** |
| 학습 라벨 | 앵커의 **동시 리셋 ≥ t\*=3** 이진 라벨 1개 (축별 5라벨 미사용) |
| 손실 | plain BCE, pos_weight = 1 (W3 결정 승계) |
| 최적화 | Adam lr 3e-4 · batch 8192 · 8 epoch · seed 0/1/2 · **마지막 epoch 사용(모델 선택 없음)** |
| 데이터 | phase1 앵커 10,598편, 분할 seed 20260728 · val 5% = **train 10,069편 / 2,643,371 전이** |

**HP 탐색 없음.** lr·epoch·dropout·pos_weight 는 M5 값을 그대로 복사했다. dev-3 로 고른 것은 없다.

### 1.3 평가 (deployable · 경계 개수 미제공)
- 지표 = **DTS Score**(`dts_scoring.score_dialogues`), AUC 보조. dev-3 3편 · gold 경계 66.
- 임계 규칙 2개 — **M5 와 동일한 함수**:
  ① 적응임계 `online_nf`, c = 1.0(🔒 D-B39, 출처 = SuperDialseg 공식 test)
  ② 문서 내 고정분위수 r = 0.0642(🔒 D-B30 앵커 val 동결. 앵커 train 실측 경계율 0.0650)
- **참조군을 같은 스크립트로 그 자리에서 재평가**했다(문서 수치 전사 금지).
  🟢 **하네스 검증 통과** — M5 W3 적응임계 **0.3963**(= `configs/m5_default.json`
  `reference_scores.W3_adopted` 정확 재현) · M5 W0 분위수 seed0 **0.4190**, M4 W0 **0.3861**
  (= `2026-07-29_baseline_compare/REPORT.md` 값과 일치).

## 3. 해석

- **5축 분해의 예측적 기여가 관측되지 않는다.** 두 임계 규칙에서 Δ 의 부호가 갈리고 크기가 전부
  노이즈 하한(앵커 동일입력 재현성 0.87 → "단일 추출 점수 차 0.06 미만은 해석하지 않는다")의
  1/4 이다. 방향을 말할 수 없다.
- **M5−M4 대조는 이 물음에 답하지 못했다.** 같은 조건(W0)에서 M5−M4 = +0.039(적응) / +0.025(분위수)로
  "요인화가 기여한다"처럼 보이지만, **5축을 아예 안 쓰는 M8 이 M4 를 크게 이긴다**
  (+0.059 / +0.040). ⇒ M4 의 약세는 "단일 잠재라서"가 아니라 **축별 라벨을 단일 잠재에 밀어 넣는
  구성 자체가 비효율**이기 때문일 수 있다. M4 는 5축 구조의 하한이 아니었다.
- **과분절이 오히려 완화된다.** 최대 미해결 문제인 과분절(M5 2.21×)이 M8 에서 1.39~1.62× 다.
  경계 라벨을 직접 학습하면 경계 밀도가 자연히 맞는다 — 5축 확률 합을 임계하는 경로가
  밀도 제어에 불리하다는 뜻이다.
- **AUC 는 M5 가 근소 우위**(0.698 대 0.688/0.679). 순위화는 5축이 조금 낫지만 **작동점을 포함한
  주지표(Score)에서 그 우위가 사라진다.** 프로젝트 규약대로 판정은 Score 로 한다.
- **앵커 val(의사-gold) AUC 는 M8 이 0.80~0.81** 로 높은데 dev-3(사람 gold)에서는 0.68 이다.
  의사-gold 를 잘 맞히는 것과 사람 경계를 맞히는 것이 다르다는 기존 관측과 일관된다.

## 4. 판정 (사전등록 §4 판정표 그대로 적용)

**1행 발동 — Δ ≤ +0.06 ⇒ "5축 분해의 예측적 기여 없음."**

- 논문에서 **5축은 예측 성능이 아니라 해석 가능성으로 정당화**한다. 성능 근거로 쓰지 않는다.
- **M8 을 본문 표에 싣는다**(사전등록: 결과와 무관하게 싣는다).
- ⚠️ 사전등록 3행("두 규칙의 부호가 갈리면 결론 없음")도 형식상 걸린다. 두 판정은 충돌하지 않는다 —
  **부호가 갈린 이유가 두 값 다 노이즈 안이기 때문**이며, 어느 쪽으로 읽어도 "M5 가 M8 을
  유의하게 넘지 못했다"는 같다. 기준을 고쳐 통과시키지 않았다.
- 🔒 이 판정으로 **바꾸지 않은 것**: 임계 계수 c=1.0, 분위수 r=0.0642, t\*=3, M5 체크포인트,
  봉인 시험지. 재학습·재탐색 없음.

## 5. 한계 / 검증 미해결

- **해석 가능성을 측정하지 않았다.** M8 이 동률이어도 "어느 축이 리셋됐는가"는 M8 에서 못 읽는다.
  5축의 남은 주장은 이 실험의 사정거리 밖이다. 정량화하려면 별도 설계가 필요하다.
- **dev-3 3편 · 3시드.** Δ 의 신뢰구간을 낼 표본이 아니다. 봉인 시험지는 열지 않았다.
- **M4 는 W0 조건뿐이다.** M4 의 pos_weight=one(W3) 체크포인트가 없어 M5 W3 와 직접 비교할 수 없다.
  본문 표의 M5−M4 비교는 **W0 끼리** 한 것이며, M4 W3 재학습은 하지 않았다(별도 결정 사항).
- **M8 은 상태가 없다**(`pair`). 온라인이지만 스트리밍 상태 모델이 아니다 —
  "구조 없는 하한"이라는 지위는 그래서 오히려 강해진다.
- **앵커 라벨 자기일치도 0.659 가 M5·M8 공통 상한**이다. 두 방법 모두 같은 증류 손실을 겪는다.
- M8 은 **앵커 라벨을 그대로 쓴다** — 5축 추출(M3) 없이는 존재할 수 없다. 이 결과는
  "5축 **파이프라인**이 불필요"가 아니라 "**모델 안의 5축 분해**가 예측에 기여하지 않음"이다.
  라벨 생산 경로로서의 5축(M3)은 이 실험의 대상이 아니다.
