## 실험 ① 교사 애블레이션 — "5축 라벨이 좋은 지도신호인가"

### 왜
M8-DirectBoundary 결과로 **모델 내부의 5축 분해**는 예측적 기여가 없다고 판정했다(2026-07-31).
그 판정 이후 5축에 남은 주장은 두 개다 — **해석 가능성**과 **지도신호(교사) 품질**.
후자는 한 번도 검정된 적이 없다. 학생(직행 경계 헤드)을 고정하고 **교사 라벨만 바꾼다.**

### 설계
- **학생 = 고정.** M8-DirectBoundary `pair` 변종(78.7만 파라미터), plain BCE,
  Adam lr 3e-4 · batch 8192 · 8 epoch · seed 0/1/2 · 마지막 epoch. **HP 탐색 없음.**
- **교사만 바꾼다** (앵커 코퍼스 10,598편, 분할 seed 20260728 동일):

| 교사 | 라벨 정의 | 무엇을 검정하나 |
|---|---|---|
| `axis5_t3` | 동시 리셋 ≥ 3 (현행) | 기준 조건 |
| `axis5_t2` / `axis5_t4` | 동시 리셋 ≥ 2 / ≥ 4 | t\* 민감도. **최선을 고르지 않는다** — 민감도 분석으로만 |
| `cosdrift` | 문서 내 코사인 드리프트 상위 r | **스칼라 교사** 대 다축 교사 |
| `space_only` | 공간 축 리셋 단독 | **동시성(coordination)** 이 필요한가, 축 하나로 충분한가 |
| `random` | 문서 내 무작위 상위 r (밀도만 일치) | 🔴 **바닥 통제.** 이게 동률이면 라벨 내용이 무의미하다 |

- r = 0.0650(앵커 실측 경계율). 무작위 시드 20260731 고정.
- 평가는 M8 실험과 **완전히 동일**: dev-3 deployable Score, 적응임계(c=1.0) + 문서내 분위수(r=0.0642),
  3시드 평균±SD, AUC 보조. 🔒 시험지 미개봉.

### 판정 기준 (실행 전 고정)
Δ = (`axis5_t3`) − (대안 교사), 두 임계 규칙 각각.

| 조건 | 판정 |
|---|---|
| `random` 과 Δ ≤ +0.06 | 🔴 **라벨 내용 무관** — 지금까지의 결과 전부가 밀도 효과다. 논문 재설계 필요 |
| `cosdrift`·`space_only` 대비 Δ > +0.06 (두 규칙 모두) | ✅ **5축 다축 교사의 우위** — 5축의 남은 주장이 수치로 선다 |
| Δ ≤ +0.06 | **구별되지 않음** — 5축은 교사로서도 특별하지 않다. 해석 가능성만 남는다 |
| 두 규칙 부호 갈림 | 개선으로 판정하지 않는다 |

- **어느 결과가 나와도 전 조건을 보고한다.** 최고만 고르지 않는다.
- t\*=3 은 이 실험으로 **바꾸지 않는다**(민감도 분석 전용).

## 실험 ② 5축 결합 방식 — "현행 M5가 5축을 낭비하고 있는가"

### 왜 (설계 가설)
현행 신호는 `s = Σ_k P(리셋_k)` — **균등 합**이다. 그 순간 5차원이 스칼라로 붕괴하므로
**직행 스칼라 헤드와 표현력이 같아진다.** 축별 발화율이 0.0213(시간) ~ 0.6950(인과)으로
30배 이상 다른데도 같은 무게로 더한다. 5축이 예측에 기여하려면 **결합이 학습되어야 한다**는
가설을 검정한다.

### 설계
- **M5 체크포인트 동결.** 재학습 없음. 축별 확률 P(리셋_k)까지는 현행 그대로 뽑고
  **결합 함수만** 바꾼다.
- 결합 함수를 맞추는 데이터 = **앵커 val 529편**(의사-gold = 동시 리셋 ≥ 3).
  🔴 dev-3 는 결합 학습에 쓰지 않는다.

| 결합 | 정의 |
|---|---|
| `sum` | Σ_k P_k (현행) |
| `logistic` | 5차원 → 로지스틱 회귀 (파라미터 6개) |
| `zscore_sum` | 축별로 val 통계로 표준화한 뒤 합 (발화율 30배 차이 보정) |
| `logistic_pair` | 5차원 + 축쌍 곱 10개 → 로지스틱 (파라미터 16개) — **동시성 패턴**을 쓰는가 |

- 평가는 실험 ①과 동일(dev-3, 두 임계 규칙, 3시드).

### 판정 기준 (실행 전 고정)
Δ = (최고 결합) − (`sum`), 두 임계 규칙 각각.

| 조건 | 판정 |
|---|---|
| Δ > +0.06 (두 규칙 모두) | ✅ **현행이 5축을 낭비하고 있었다** — 결합을 교체하고 M8 과 재대결 |
| Δ ≤ +0.06 | **결합 방식이 원인이 아니다** — 5축의 예측적 기여 없음 판정이 강화된다 |
| `logistic_pair` 만 크게 이김 | **동시성 패턴에 정보가 있다** — H1(다축 동시 리셋)의 직접 근거. 재학습 설계로 승격 |

- 결합 4종 중 **dev-3 에서 최고를 고르지 않는다.** 선택이 필요하면 앵커 val 로 하고,
  dev-3 는 전 조건을 나란히 보고한다.
- 이 실험으로 바꾸지 않는 것: M5 체크포인트, 임계 계수 c=1.0, r=0.0642, t\*=3, 시험지.

## 두 실험에 공통으로 적용

- **주지표 = DTS Score**, AUC 보조. dev-3 절대값은 성능으로 인용하지 않는다 — Δ·방향만.
- 실질성 한계 **0.06** = 앵커 동일입력 재현성(0.87)에서 유도한 노이즈 하한. 사후 변경 금지.
- 예측 경계 수와 과분절 배수를 **함께** 보고한다(사람 BOR ≈ 1.0 이 기준선).
- 5축 중 어느 축도 제거하지 않는다.
