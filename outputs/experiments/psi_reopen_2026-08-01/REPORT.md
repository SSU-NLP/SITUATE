# ψₑ(에피소드 스키마 요약) 재개봉 — 앵커 게이트 전부 미달, 트랙 종료

**결론 먼저.** ψₑ 를 두 앵커 라벨(`phase1_i2` · `phase1_chainq_i2`) × 두 분할(청크 무작위 ·
책 단위) × 두 임계 규칙 × 앵커/dev-3 양쪽에서 재시험했다. **어느 조합에서도 사전 선언한 게이트를
넘지 못했고, 이득의 방향조차 split 마다 뒤집힌다.** D-B30 의 기각을 유지한다 — 이번엔 ψ 가
"반쪽만 켜진" 조건이 아니라 **dynamics 예측오차가 판정기까지 연결된 조건(C)** 에서도 그렇다.

부수 산출로 **val 세트의 책 단위 누수**를 정량화했다: J_anchor 가 `phase1_i2` 에서 **0.0159**,
`phase1_chainq_i2` 에서 **0.0077** 부풀려져 있었다(seed 잡음 0.00078 의 10~20배).

> 사전 선언 문서: [`DECISION.md`](DECISION.md) (배치 착수 **전** 작성, 게이트 동결).
> caveat: **seed 1개**(사용자 지시, 빠른 선별) · 앵커 k=1 · S_self 0.659(상한) · dev-3 = 연습장 3편.
> 탐색적 결과이며 성능 주장이 아니다.

## 1. 실험 setup

### 목적
`factored-slot-eism-v0_1.md` §4.3 의 **스키마 조건부 dynamics** `sₜ^(k) = f^(k)(s_{t-1}^(k); ψₑ)` 를
재시험한다. ψₑ = *같은 에피소드 안에서 축 k 가 지금까지 어떻게 유지돼 왔는지를 요약한 벡터*.

D-B29/D-B30 에서 이미 기각(최고 Δ −0.0006, 기준 +0.005)됐으나 두 근거로 재개봉했다:
1. **그때 ψ 는 판정기에 연결되지 않았다.** Ψ 묶음은 `head_feat=delta` 로 돌았고, 그 조건에서는
   dynamics 예측 `ŝ = f(s;ψ)` 가 change head 입력에 **들어가지 않는다**
   (`src/hi_ontop/factored_slot.py:471` — `sh` 는 `head_feat != "delta"` 일 때만 계산).
   ψ 는 head 에 붙은 추가 특징일 뿐이었다.
2. **앵커 라벨이 바뀌었다.** 그때 split 은 구 `phase1`. 지금은 의도축 교체(`_i2`)와 인과축
   Qwen3.6 사슬 교체(`_chainq_i2`)가 적용된 다른 라벨이다.

### 데이터
| 항목 | 값 |
|---|---|
| 코퍼스 | Project Gutenberg 3,032권 → **10,598 청크 · 2,788,159 문장 · 2,777,561 전이** |
| 임베딩 | `sentence-transformers/paraphrase-multilingual-mpnet-base-v2`, 768D fp16 memmap, L2=1.0 |
| 앵커 라벨 | 5축 reset 행렬(LLM 라벨러 의사-gold). 의사-gold 경계 = `count ≥ t*=3` |
| `phase1_i2` | 축별 발화율 [0.3049, 0.1047, 0.0213, 0.6950, 0.1172] · **경계율 6.57%** |
| `phase1_chainq_i2` | 인과축만 교체(전이의 63% 가 다름) → [.., .., .., **0.1384**, ..] · **경계율 2.45%** |
| dev-3 | pieman / tunnel / monkey (3편 · 1,005 전이 · gold 66경계). 학습 코퍼스와 **교집합 없음** |
| 봉인 test | 열지 않음 |

전처리 점검(전부 PASS): emb↔index 정합 · **문서 경계를 넘는 전이 없음**(전이수 = 문장수−문서수) ·
resets ∈ {0,1} · NaN/0벡터 없음 · doc_id 중복 0 · i2 vs chainq 는 인과축만 다름.

### 방법 (조건 4종 + 기준선)
공통: M5-FactoredSlot · `dynamics per_slot` · `pred_space slot` · `pos_weight one` ·
slot_dim 128 · bottleneck 8 · dropout 0.4 · lr 3e-4 · **epochs 8**(early stopping 없음, 마지막
epoch 저장) · batch 48 · **seed 0** · `--dev3` 미사용.

| 조건 | `--psi` | `--head-feat` | 의미 |
|---|---|---|---|
| 기준선 | none | delta | 현행 M5. 판정기 입력 `[a, b, b−a, b⊙a]` |
| **A** | cummean | delta | 에피소드 누적평균 ψ. D-B29 Ψ 재현 |
| **B** | ema | delta | EMA(β=0.9) ψ. 〃 |
| **C** | cummean | **resid_signed** | 입력에 `b−ŝ` 추가 → **ψ 조건부 예측오차가 판정기에 도달하는 유일한 조건** |
| **D** | none | resid_signed | **대조군.** C 의 변화가 ψ 덕인지 잔차 덕인지 분리 |

ψ 리셋: 학습 = 앵커 경계(teacher reset dropout 0.3) · 추론 = **rollout**(자기 예측 경계로 리셋,
`change_probs_rollout`). 앵커를 추론에 쓰면 누출이므로 경로가 다르다.

### 분할 2종
- **청크 무작위**(현행): 문서(=청크) 단위 무작위. train 10,069 / val 529.
- **책 단위**(신규 `--group-split book`): 같은 책(`pgXXX`)은 train/val 한쪽에만. train 10,066 / val 532.
  J_anchor 의 5-fold 도 책 단위로 나눠 임계 규칙 선택 단계의 누수까지 차단.

### 지표
- **선별 지표 = J_anchor** (앵커 val 5-fold OOF **deployable** Score). 임계 규칙 선택조차 out-of-fold.
- dev-3 = `Score · BOR · purity · coverage · F(p,c) · L1`, 두 임계 규칙(고정분위수 = 앵커 동결 /
  적응임계). 전부 동결 구현 호출(`dts_scoring.score_dialogues`, `full_comparison_dev3.purity_coverage`,
  `lift_l1`) — 재구현 없음.

### 🔒 사전 선언 게이트 (결과 보기 전 확정, [`DECISION.md`](DECISION.md) §3)
- **G1**: A 또는 B 가 같은 split 기준선 대비 **+0.005 이상**
- **G2**: **C − D ≥ +0.005** (같은 split·같은 seed)
- 어느 한 split 에서라도 통과 → 그 조건만 3-seed 본선. 전부 미달 → **ψ 트랙 종료**
- 두 분할이 엇갈리면 **책 단위 분할을 신뢰**한다

## 4. 해석

**① ψ 는 어느 조건에서도 이득을 주지 않는다 — 이번엔 변명거리가 없다.**
D-B29 기각은 "ψ 가 판정기에 연결되지 않은 조건에서 시험됐다"는 반론이 가능했다. 이번 C 조건이 그
연결을 켰다. 그런데도 C−D 가 8칸 중 어디서도 게이트를 못 넘고 부호가 split 마다 뒤집힌다
(책·i2 +0.0045 vs 책·chainq −0.0071). 설계문서 §4.3 이 *"IDM 과의 구조적 차이"* 라고 선언한 축은,
라벨을 갈아끼우고 누수를 제거한 뒤에도 **측정 가능한 이득을 주지 않는다.**

**② ψ 는 오히려 과분절을 키우는 쪽으로 작동한다.**
적응임계에서 C 의 BOR 이 chainq 양쪽 분할 모두 2.50 으로 최고다. 추정 기전(미검증): rollout 추론은
모델이 스스로 경계를 찍으면 ψ 를 리셋하는데, 리셋 직후에는 요약이 비어 다음 전이가 상대적으로 크게
보이고 → 또 경계 → 연쇄. **ψ 의 원래 취지(흐름을 알면 가짜 경계를 억제)와 반대 방향이다.**

**③ 청크 분할에서 ψ 가 크게 나빠 보였던 것(i2 −0.009/−0.010)은 누수와 얽혀 있었다.**
책 단위 분할에서는 같은 조건이 +0.0032/+0.0002 로 올라온다. 즉 "ψ 가 해롭다"는 강한 주장은
**철회한다** — 정확한 서술은 **"ψ 는 무효이며, 청크 분할에서 관측된 큰 하락은 분할 아티팩트를 포함한다"**.

**④ 책 단위 누수는 실재하고 크기는 0.008~0.016 이다.**
seed 잡음(0.00078)의 10~20배. D-B29 라인의 J_anchor 절대값은 전부 이만큼 낙관적이었다. 다만
**조건 간 비교에는 영향이 없었다** — 두 분할이 같은 게이트 판정(전부 미달)을 냈다.

**⑤ 임계 규칙이 split 순위를 뒤집는다 (ψ 와 무관, 별건).**
고정분위수: chainq(0.426) > i2(0.402). 적응임계: i2(0.397) > chainq(0.383). 앞선 W3/I2/chain 판정은
**적응임계**로 냈었다. 인과축 교체의 가치 판정이 규칙 선택에 의존한다 — 별도로 다뤄야 한다.

**⑥ 개수를 맞춰도 인간과의 격차는 남는다.**
고정분위수에서 BOR 1.02(인간 개인과 같은 밀도)인데 Score 0.40~0.43. 인간 개인은 같은 채점기에서
pieman 0.499 / tunnel 0.542(D-B59). **남은 격차는 밀도가 아니라 경계 위치다.** L1 3.4~3.9 로
순위력 자체는 무작위의 3~4배 살아 있다.

## 6. 한계 / 검증 미해결

- 🔴 **seed 1개.** 사용자 지시(빠른 선별)에 따른 것이며 [`DECISION.md`](DECISION.md) §1 에 "선별이지
  채택 결정이 아니다"로 사전 명시했다. 게이트 미달이라 본선을 안 돌렸으므로 **"ψ 가 +0.005 를 넘지
  못한다"는 1-seed 근거**다. 0.002 규모 차이는 판독 불가.
- 🔴 **책·i2 의 C−D = +0.0045 는 게이트(0.005) 바로 아래다.** 결과를 보고 기준을 낮추지 않는다.
  다만 같은 칸이 chainq 에서 −0.0071 로 **부호가 반대**라, 기준을 낮췄어도 "일관된 이득" 조건은
  못 넘는다. 굳이 재판정하려면 **C vs D 만 3-seed 로, 기준을 먼저 선언하고** 돌리는 것이 순서다.
- **ψ 과분절 기전(②)은 추정이다.** rollout 리셋 연쇄를 직접 계측하지 않았다(리셋 시점 분포 미수집).
- **ψ 는 최소형 2종뿐**이다(누적평균·EMA). 설계문서 원형 — ψₑ 가 causality/goal MoG 의 혼합가중·평균을
  파라미터화하는 형태 — 는 여전히 미구현이며, 이번 기각은 그 형태에 대한 기각이 아니다.
- **dev-3 = 3편 연습장**이고 pieman 선택압이 누적돼 있다. §3 은 방향 확인 이상으로 쓰지 않는다.
- 앵커 k=1 · S_self 0.659 = 대리 지표의 천장. J_anchor 0.40 은 사람 경계 성능이 아니다.
