# 작동점(적응임계) 민감도 — EM-LLM 규칙 이식 포함 (2026-08-04)

**판정: EM-LLM 규칙을 그대로 가져와도 나아지지 않는다.** γ=1.1 은 채택값 c=1.0 보다 세 모델
모두 Score 가 낮고(−0.002 ~ −0.012), 이동창은 이 문서 길이에서 전체 과거로 퇴화해 효과가 없다.
**모델 순위(M8 > M4 > M5)는 세 온라인 작동점 전부에서 유지된다** — 순위는 임계 규칙의 산물이 아니다.
단 **개수를 통제하면(quantile) 세 모델이 구분되지 않는다**(0.405/0.409/0.408).

⚠️ **이것은 작동점 선택이 아니다.** 채택 작동점은 `online_nf c=1.0`(D-B39) 그대로다.
결과를 보고 기준을 바꾸지 않는다.

## 1. 실험 setup

| 항목 | 값 |
|---|---|
| 목적 | 모델 순위가 작동점에 의존하는가 + EM-LLM 발표 임계 규칙이 우리 점수에 이득인가 |
| 러너 | `scripts/eacl_phase0/threshold_sensitivity.py` (신규, 기존 평가 스크립트 무수정) |

| 모델 | M5(5슬롯) · M4(1슬롯 공유) · M8(=M8-pair, 단일 이진 MLP). **체크포인트·점수 전부 동일**, 이진화 규칙만 교체 |
| seed | 4 (모델별 seed0~3), 표는 seed 평균 |
| 지표 | Score(주) = 0.5·F1+0.25(1−Pk)+0.25(1−WD), `hi_ontop.dts_scoring.score_dialogues` · BOR=예측/정답 경계수 · Lift · AUC(임계 무관) |
| 장치 | CPU (GPU 점유 중이라 회피, 결과 동일) |

### 작동점 4종

| 이름 | 규칙 | 출처 | 온라인 |
|---|---|---|---|
| `adopted_c1.0` | `s_t ≥ μ_<t + 1.0·σ_<t` (전체 과거) | D-B39. c=1.0 은 DTS 공식 test 36,109 전이가 선택 | ✅ |
| `emllm_gamma1.1_fullpast` | `s_t > μ_<t + 1.1·σ_<t` (전체 과거) | EM-LLM **계수만** 이식 — γ 효과와 창 효과 분리용 대조군 | ✅ |
| `emllm_sm_win4096` | `s_t > μ(win) + 1.1·σ(win)`, win = 직전 4096 **토큰** | EM-LLM 원 규칙 (`em_llm.py:19`, `config/llama3.yaml:19`) | ✅ |
| `quantile_0.0660` | 문서 내 상위 6.60% 분위수 | I2 앵커 경계율. 개수를 고정 → 모델 간 BOR 동일 | ❌ |

γ=1.1 · n_local=4096 · warmup=3 은 **EM-LLM 발표값 고정**, 우리 데이터로 튜닝하지 않았다.
🔴 `quantile` 은 문서 전체 분포가 있어야 임계가 정해지므로 **오프라인**이다 — 온라인 성능 주장에
쓸 수 없고, "개수를 통제하면 모델이 구분되는가"를 보는 진단용으로만 넣었다.

## 3. 해석

**① EM-LLM 계수는 우리 점수에 이득이 아니다.** γ 1.0→1.1 은 임계를 올려 과예측을 줄이지만
(BOR 평균 M5 2.17→1.96), Score 는 세 모델 모두 내려간다. 이유는 두 방향이 상쇄되기 때문이다 —
과예측이 심한 tunnel·monkey 에서는 +0.008~+0.017 로 이득이지만, 이미 과소예측인 pieman
(BOR 0.78→0.64)에서 −0.070 으로 크게 잃는다. **경계 밀도가 문서마다 5배 차이 나는데 계수 하나로는
양방향을 동시에 못 고친다.**

**② 이동창은 이 데이터에서 작동하지 않는다.** γ 고정하고 창만 켜면 M5 +0.008 · M4 0.000 · M8 −0.001.
문서가 1.2k~6.2k 토큰이라 4096 창이 과거의 93~100% 를 덮어 **전체 과거와 구분되지 않는다**
(`2026-08-03_emllm_sm_dev3` §4 의 커버리지 0.975 와 정합). EM-LLM 의 n_local 은 무한문맥 LLM 의
로컬 캐시 크기이지 분절을 위해 조율된 값이 아니며, 서사 한 편 길이에서는 무의미하다.

**③ 모델 순위는 임계 규칙의 산물이 아니다.** 세 온라인 작동점 전부에서 M8 > M4 ≥ M5 순서가
유지된다(M8 평균 0.394 / 0.384 / 0.383). 임계를 바꿔 M5 를 구제할 수 있다는 가설은 기각된다.

**④ 구분되지 않게 만드는 것은 임계가 아니라 개수 통제다.** quantile 에서 세 모델은
0.405 / 0.409 / 0.408 로 폭 0.004(seed 편차 이내)다. 이때 BOR 은 설계상 세 모델 동일(0.876)이므로
Score 차이는 **순수 위치 차이**이고, 그 차이가 없다는 뜻이다. AUC 도 0.656/0.661/0.660 으로 같다.
⇒ **세 모델의 경계 순위화 능력은 동일하고**, 온라인 작동점에서 M8 이 앞서는 것은 M8 의 점수 분포가
μ+cσ 규칙과 잘 맞아 **개수를 덜 틀리기 때문**이다. D-B70 ⑤ 판정과 같은 방향이며 근거가 하나 늘었다.

## 4. 판정

| 물음 | 답 |
|---|---|
| EM-LLM 임계 규칙을 채택할 이유가 있나 | **없다.** 세 모델 모두 Score 하락, 창은 무효 |
| 채택 작동점 `online_nf c=1.0` 을 바꾸나 | **바꾸지 않는다.** 본 결과는 민감도 기록일 뿐 |
| 논문 문단 ②("5차원 분해 > 단일 신호") | **여전히 성립 안 함.** 작동점 4종 어디서도 M5 우위 없음 |
| 다음 | 임계 계수 탐색은 닫는다. 남은 여지는 **개수 자가결정 기전**(온라인 분위수/확률 보정)이며, 그건 새 작동점 사전선언 + 새 봉인셋이 있어야 정당하다 |

## 5. 한계 / 검증 미해결

- **사후 분석이다.** 6편 결과를 이미 본 뒤 돌렸다. 여기서 어떤 작동점이 좋아 보여도 확증 성능으로
  주장할 수 없다(codex 자문 및 `no-postresult-criterion-change`). 본 REPORT 는 "바꾸지 않는다"는
  근거로만 쓴다.
- **test3 3편은 이미 2회 개봉**되어 개발셋으로 강등된 상태다(D-B70 ⑧). 6편 전부 개발 성격이다.
- **quantile 은 오프라인**이라 온라인 표에 나란히 둘 수 없다. 개수 통제 진단용이다.
- γ 스윕을 하지 않았다 — 의도적이다. 발표값 1.1 만 썼고, 스윕은 dev 튜닝이 된다.
- 확률 보정(Platt/isotonic) · 온라인 분위수 추정 · 인과적 불응기(NMS)는 **미실행**. 앞의 둘은
  "임계값을 앵커에서 정하면 의사-gold 작동점 선택"이라는 ledger 규칙과 충돌 여부를 먼저 정리해야 한다.
- 과예측이 인접 중복인지 고립 오검인지 **미진단**. 이 진단이 NMS 계열의 가치를 좌우한다.
