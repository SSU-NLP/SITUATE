# M5 vs M4 vs M8 — 인물키 코퍼스 · I2 앵커 (2026-08-04)

**판정: 세 모델이 구분되지 않는다.** 6편 평균 Score 폭 0.008(0.401~0.409)로
작품별 편차(0.27~0.53)의 1/8. **표현 분해(M5−M4)도 신호 분해(M5−M8)도 예측 성능 이득이 없다.**
남는 주장은 해석 가능성이며, 그 근거는 축 leave-one-out 의 `space` 뿐이다(§5).

🔒 지위 = **탐색적**(ledger D-B16). M5−M4 를 가설 지지라 부르지 않고 부호·방향만 읽는다.
앵커 k=1 · S_self 0.659(상한) caveat 유지.

### 모델 차이 — 이것만 다르다

| | 잠재 | 헤드/손실 | 경계 점수 | 격리 |
|---|---|---|---|---|
| M5-FactoredSlot | 5슬롯(축별) | 5축 리셋 | `Σₖ P(resetₖ)` | (제안) |
| M4-MonoAnchor | **1슬롯 공유** | 5축 리셋 | `Σₖ P(resetₖ)` | 표현 분해 |
| M8-DirectBoundary | 1 (MLP 79만) | **경계 1개**(`count≥3`) | `P(boundary)` | 신호 분해 |

M8 라벨은 M5 라벨의 결정적 함수(`resets.sum(1)≥3`)이므로 **M5 가 정보를 가장 많이 받는다.**
셋 다 사람 경계는 학습에 쓰지 않는다.

### 지표

`Score = (2F1 + (1−Pk) + (1−WD))/4` 문서단위 평균 · **BOR** = 예측/정답 경계 수 ·
**Lift** = `P(y=1|ŷ=1)/P(y=1)` · **AUC**(임계 무관) · **퇴화 하한**(무예측 Score) 병기.

⚠️ dev-3 과 시험지는 gold 밀도·퇴화 하한이 다르다 — **작품 간 절대 Score 비교 금지.**

## 3. 해석

**세 모델이 구분되지 않는다.** 6편 평균 Score M5 0.405 · M4 0.409 · M8-pair 0.408 · M8-ctx 0.401.
폭 0.008 은 seed 편차(±0.004~0.014)와 겹치고, 작품별 편차(0.27~0.53)의 1/8 이다.
승패도 흩어진다 — Score 는 M4 2승·M8-pair 2승·M5 2승, 지표를 바꾸면 순위가 바뀐다
(Score=M4 · Lift=M8-pair · AUC=M4).

**정보를 가장 많이 받는 M5 가 79만 파라미터 이진분류기(M8)와 동률이다.** M8 라벨은 M5 라벨의
결정적 함수이고 M5 는 학습 중 그 경계 신호까지 teacher 로 쓴다. 그럼에도 이득이 없다.

**BOR 이 네 모델 동일(0.876)** 이므로 Score 차이는 전부 *경계 위치* 차이다. 개수 정책은 변수가 아니다.
전 작품 BOR<1 = 과소분절인데, 이는 앵커 경계율 0.0660 을 쓰고 평가셋 gold 밀도(0.036~0.190)를
쓰지 않기 때문이다. **oracle 누출을 피한 대가이며 방법의 실제 한계다.**

**`test3/run` 은 네 모델 모두 실패한다** — Score 0.270~0.305 로 퇴화 하한 0.3288 아래, Lift 0.000,
AUC 0.51~0.54. gold 정렬을 세 경로(gate·index·master)에서 확인했고 오류가 없다.
gold 를 직접 읽은 결과 **경계의 상당수가 서사→설명 전환에 찍혀 있다**(아파르트헤이트 미니버스
제도 설명 3연속, Zulu/Xhosa 고정관념 설명 등). 우리 5축은 상황 모델을 추적하므로 그 지점에서
발화할 이유가 없다. **구성개념 불일치이지 모델 결함이 아니다** — ledger 의 Monkey(저널리즘) ·
SHARE(모달리티)에 이은 세 번째 경계조건 사례.

## 5. 축 leave-one-out (readout LOO)

학습된 체크포인트에서 **읽기 단계만** 축을 빼 경계 점수를 다시 만든다. 6편 · seed 4개 · 적응임계.

| view | M5 ΔScore | M4 ΔScore |
|---|---|---|
| full | 0.4038 | 0.4098 |
| −protagonist | −0.0070 | −0.0111 |
| **−space** | **−0.0432** | **−0.0417** |
| −time | −0.0120 | −0.0093 |
| −causality | −0.0063 | **+0.0035** |
| −intentionality | −0.0015 | −0.0047 |
| only:space | −0.0113 | −0.0114 |
| only:protagonist | −0.0913 | −0.0679 |
| only:intentionality | −0.1181 (Lift 1.083) | −0.1073 (Lift 1.285) |

**`space` 가 유일하게 강한 축이다.** 빼면 −0.043 으로 seed 편차(±0.011)를 크게 넘고 단독으로도
−0.011 에 그친다. 무대 리셋이 사람 경계를 만든다는 EISM 주장과 직결된다.

**`intentionality` 는 기여가 없다.** 빼도 −0.002, 단독 Lift 1.08 로 거의 무작위. I2 정의로 바꿔도 같다.

**🔴 축 기여 패턴이 M5 와 M4 에서 거의 같다.** 표현을 하나로 합쳐도 다섯 헤드가 서로 다른 것을
예측한다 ⇒ **축이 기능하는 것과 축마다 잠재를 따로 두는 것은 별개다.** M4 에서 `causality` 만
방향이 갈린다(+0.0035, 빼는 게 이득) — 발화율 0.69 로 가장 자주 켜져 공유 잠재에서 다른 축을
잠식했을 가능성.

⚠️ **readout LOO 이지 재학습 LOO 가 아니다.** 5축이 함께 학습된 표현은 그대로 두고 읽기만 뺐다.
축을 빼고 재학습한 결과와는 다르며, 그건 `n_slots=5` 하드코딩을 손봐야 하는 별도 작업이다.
⚠️ 진단 전용 — 축을 신호에서 제거하자는 제안이 아니다(5축 유지 원칙).

## 6. 한계 / 검증 미해결

- **n=6.** 작품 간 편차가 모델 간 차이보다 훨씬 크다. 어느 모델도 우세를 주장할 수 없다.
- **dev-3 은 연습장**(pieman 선택압 9회 누적). 절대 Score 를 성능으로 인용하지 않는다.
- **시험지가 개발셋으로 강등됐다** — 8 vs 40 epoch 을 시험지 위에서 비교했다(`eval-suite-spec.md` 2차 개봉).
  epoch 관련 주장은 held-out 증거로 쓸 수 없다.
- **I2 vs frozen 축은 구분되지 않는다.** 6편 평균 Score −0.018~+0.003, AUC 는 세 모델 모두 I2 에서
  소폭 하락. I2 를 쓰는 이유는 성능이 아니라 **다운스트림(EM-LLM) 조건 일치**다.
- **M8 의 목적함수가 평가 형태와 정렬돼 있다** — 경계 확률을 직접 출력한다. M5 는 축별 학습 후
  추론 시점에 합산한다. 불공평이 아니라 분해 방식이 치르는 대가이나, 논문에 명시해야 한다.
- **EM-LLM NarrativeQA 미실행.** 4번째 문단(다운스트림) 근거는 구 체크포인트 표(M5 +1.79)뿐이며
  오늘 조건으로 재실행하지 않았다. M8 어댑터도 미구현.
- **재학습 LOO 미실행** (위 §5).
