## 3. 해석

- 🔴 **동결본은 계열의 중앙값보다 낮다** (0.3888 vs 0.3943, 132개 중 85위). 상위 변형을 골랐다면
  시험지에서 **0.4505** 가 나왔고, 이는 main 표 1위(LLM 직접질의/GPT-4.1 0.4010)를 넘는다.
  **그래서 고르지 않는다** — 이것이 정확히 selection-on-test 다. 이 문단은 "우리가 이길 수도 있었다"
  는 주장이 **아니라**, 시험지 점수로 고르면 얼마나 부풀릴 수 있는지의 크기를 적어 둔 것이다.
- 🔴 **변형 선택의 폭(0.3092~0.4505 = 0.141)이 main 표의 방법 간 격차(0.01~0.02)보다 한 자릿수 크다.**
  ⇒ 시험지에서 *"M5 가 GPT-4.1·TextTiling 보다 낮다"* 는 순위는 **변형 선택 노이즈 안에 있다.**
  양방향으로 읽어야 한다 — 우리에게 유리한 쪽으로도, 불리한 쪽으로도 결론을 세울 수 없다.
- **현행 계보(phase1_i2)가 구세대(phase0)보다 시험지에서 낮다** (중앙값 0.3797 vs 0.4033).
  현행 계보는 dev-3·앵커 정렬에서 채택된 것이므로, 이 역전은 **dev 에서의 선택이 시험지로
  전이되지 않았다**는 뜻이다. 미해명이며 여기서 계보를 바꾸지 않는다.
- **1 epoch 스모크 체크포인트가 최상위권**이다(0.4505·0.4272). 8 epoch 본학습이 시험지에서
  더 낫다는 근거가 없다. dev-3 에서 본학습이 나았던 것과 어긋난다 — 역시 미해명.
- **작동점 효과는 작다** — adaptive − quantile 중앙값 차이 +0.001. 시험지에서는 두 작동점이 사실상 같다.
- 경계를 하나도 안 찍은 퇴화 체크포인트가 2개 있다(둘 다 `smoketest` ep1). 성능이 아니라 퇴화로 읽는다.

### (b) 상위 20 중 19개가 **의도 축 리셋 규칙이 다른** 것들이다

🔴 **정정**: 초기 서술에서 이를 *"다른 앵커 라벨"* 이라 적었으나 **틀렸다.** LLM 라벨은 양쪽이
**완전히 동일**하다(같은 코퍼스·같은 라벨러·같은 프롬프트, 추가 API 0). 다른 것은 저장된 라벨에서
**의도 축의 리셋 열만 다시 계산한 규칙** 하나뿐이다(`recompute_axes.py`).

| 앵커 라벨 (전 계보 공통) | 값 |
|---|---|
| 코퍼스 | Phase-1 앵커 10,598편 · 2,777,561 전이 (D-B15) |
| 라벨러 | **Qwen3.6-35B-A3B fp8 no-thinking** (temp 0, batch 20, k=1) |
| 프롬프트 | **`p0s5-eism-v3.1`** (= v2 + H + E, D-B14 동결) |
| 산출 | `outputs/eacl_phase0/phase1_all_v31/reset_matrix.jsonl` |

| 의도 축 리셋 규칙 | 정의 |
|---|---|
| **동결(carry∞)** — 상위권 다수 | carry-forward 무한 적용 + none 가드 |
| **채택만(i2)** — 현행 동결본 | carry-forward 미적용, 직전 `none` → 다음 목표일 때만 리셋 |

두 규칙의 실제 차이:

| 축 | 불일치율 | 발화율 |
|---|---:|---|
| 주인공·공간·시간·인과 | **0.00%** | 변화 없음 |
| 의도 | **6.68%** | 0.1140 → 0.1172 |
| 5축 동시 리셋 수 | 6.68% | count≥3 경계율 0.0649 → 0.0657 |

**전이의 6.7% 에서 한 축 한 칸이 바뀐 것이 전부인데 시험지 평균이 0.026 갈린다.**

| | 상위 20 |
|---|---|
| 동결본과 같은 규칙(**채택만 i2**) | **1개** — 그마저 `8 epoch → 1 epoch` + `슬롯 강제 리셋` 이 추가로 다르다 |
| **동결(carry∞)** 규칙 · 스모크 코퍼스 | **19개** |

### (e) 🔴 결정적 — dev-3 순위는 시험지로 **전이되지 않는다**

같은 132개를 dev-3 에서도 채점했다(`results_dev3.json`, 러너 동일).

| 비교 | n | Spearman ρ |
|---|---:|---:|
| 전체 (적응 임계) | 132 | **−0.147** (p=0.093) |
| 퇴화(경계 0) 제외 | 130 | **−0.201** (p=0.022) |
| 1-epoch·스모크 제외 | 114 | **−0.208** (p=0.026) |
| 현행 계보 안에서만 | 21 | +0.199 (p=0.39) |
| 구 계보 안에서만 | 70 | +0.230 (p=0.056) |
| 전체 (고정분위수 작동점) | 132 | +0.424 (p=4e-07) |

- **dev-3 상위 10 의 시험지 순위**: 94 · 97 · 115 · 85 · 86 · 24 · 120 · 71 · 122 · 96 — 하나(24위)만 상위권.
- **시험지 상위 10 의 dev-3 순위**: 121 · 90 · 112 · 103 · 99 · 100 · 43 · 37 · 44 · 118.
- **동결본**: dev-3 **5위**(0.4049) → 시험지 **86위**(0.3888).
- **dev-3 최고를 골랐다면**(`..._pwone_seed1`) 시험지 0.3857 = **94위**로 동결본보다 나빴다.

⇒ **dev-3(문서 3편)는 이 계열에 대해 선택력이 없다.** 적응 임계 작동점에서는 상관이 0 이거나
약한 음수다. 고정분위수 작동점에서만 +0.42 로 전이되는데, 이는 적응 임계가 문서별 통계에
의존해 **작은 표본에서 순위를 흔든다**는 뜻으로 읽힌다(미검증 가설).

🔴 이것이 이 실험의 가장 중요한 결과다 — **"시험지에서 M5 가 3위"보다 "dev-3 로는 무엇도 고를 수
없다"가 더 큰 문제**다. 현행 동결본이 dev-3 5위였다는 사실은 시험지 성능을 예측하지 못했다.

## 5. 한계 / 검증 미해결

- **시험지 유효 n ≈ 1** — 3편 전부 같은 작품·저자·주석자 풀. 132개 순위는 문서 3편 평균 위의 순위다.
- **132개 전부가 같은 앵커 라벨 계보를 공유하지 않는다** (Qwen/gemma/gpt-oss 앵커 혼재).
  계보별 중앙값은 n 이 3~70 으로 불균형이라 계보 비교는 시사적 수준이다.
- **구세대 우위·스모크 우위의 원인 미규명.** dev-3 와 시험지의 역전을 설명하지 못한다.

- **이 표를 보고 어떤 설정도 바꾸지 않았다.** 바꿨다면 그 순간 시험지는 dev 가 된다.
