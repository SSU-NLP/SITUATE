# D-B35 — 태거가 정의한 축 공간(설계문서 §4.6 진짜 D1): **덧붙이면 이기고, 대체하면 진다**

> 🔒 **결론 한 줄**: 태거 신호를 학습형 입력에 **덧붙이면**(hybrid) 기준선을 이긴다 —
> 오늘 세션에서 사전 판정 규칙을 통과한 **유일한 개선**이며, **dev-3 3편 전부에서** 좋아진다
> (monkey 포함 — 이것도 처음). 반대로 태거로 임베딩을 **대체하면**(replace) 크게 진다.
> ⇒ §4.6 D1 의 문자 그대로("discovery 는 dynamics 에만 산다")는 **기각**, 태거는 **보강 신호**다.

---

## 1. 실험 setup

### 목적
D-B34 가 *"M5−M4 이득의 실질 전부가 입력경로에서 온다"* 를 확인했으나, 그 입력경로는
`768D → 32 → 8D` **학습형**이고 축이 무엇인지 아무도 알려주지 않는다(문서 분류로는 D2).
§4.6 의 **D1** = *"run cheap NER/coref/time-tagger at inference"* 를 실제로 만들어 비교한다.

### 데이터 · 피처
- 코퍼스·임베딩·앵커 라벨·평가셋은 D-B34 와 **완전히 동일**(phase1 10,598편 / dev-3 3편 gold 66).
- 신규: `extract_axis_features.py` — spaCy `en_core_web_sm`(NER+POS+morph) + 어휘 사전으로
  **문장당 축별 8차원 = 40차원**. 2,788,159 문장 처리 ~8분, 추론 1,069 문장/초, **LLM 없음**.
- 축별 신호: protagonist(PERSON·인칭대명사·PROPN·주어 유생성) · space(GPE/LOC/FAC·장소전치사·
  이동동사) · time(DATE/TIME·시제·완료상·시간부사/전치사) — 여기까지는 **태거가 직접** 잡는다.
  causality(인과/대조/조건/순차 접속어·절 수·부정) · intentionality(의도동사·목적 to·양태·
  명령형·사고동사·인용·미래) — ⚠️ **어휘 사전만**(설계문서 §10 이 인정한 한계).
- 🔒 누출 방지: 정규화 mean/std 는 **앵커에서만** 구해 저장하고 dev-3 에 그대로 적용. 행 정렬은
  문서별 문장 수까지 검증 후 진행(phase1 2,788,159 · dev3 1,008 일치 확인).

### 방법 (4셀 × 3 seed = 12 run · 전 셀 D-B30 기준선 HP)
slot_dim 128 · bottleneck 8 · dropout 0.4 · lr 3e-4 · epochs 8 · batch 48 · pred_space slot ·
dynamics per_slot · head_feat delta · psi 없음.

| 셀 | 슬롯 k 의 입력 | 대체 축 |
|---|---|---|
| replace-3 | 태거 8D **그대로** | protagonist/space/time (나머지 2축은 E_k 유지) |
| replace-5 | 태거 8D 그대로 | 전 축 — **z 를 아예 안 본다** |
| hybrid-3 | `[E_k(z) 8D, 태거 8D]` | 앞 3축 (나머지는 태거 자리 0) |
| hybrid-5 | `[E_k(z) 8D, 태거 8D]` | 전 축 |
| 기준선 | `E_k(z) 8D` | — (D-B33 `M5_per_slot_slot` 3 seed 재사용) |

### 지표 (D-B33 부칙 1·2 + D-B34 정정 3 승계 · 사후 교체 금지)
dev-3 Score, 전 셀 동일 규칙 3종(otsu · online μ+1.0σ · offline μ+1.0σ). 임계 선택 없음.
판정 = 규칙 3종 중 ≥2 · seed 3 중 ≥2 · 문서 3편 중 ≥2 방향 일치. AUC·gold밀도(oracle)는 진단.

## 3. 해석

**① 태거는 보강 신호이지 대체재가 아니다.** replace 는 두 조건 모두 크게 열세이고 **AUC 가
−0.053/−0.071 로 무너진다** — 순위력 자체가 손상됐다. 40차원 태거 피처는 768D 임베딩이 담은
정보의 일부만 담는다. ⇒ **§4.6 D1 의 문자 그대로("extractor-defined space, discovery 는 dynamics
에만")는 기각.** 남는 방향은 **D3(anchored latent)** — 임베딩을 유지한 채 태거로 보강하는 형태이며,
그것이 곧 hybrid 다.

**② hybrid 는 3축·5축 모두 우세하고 차이가 거의 없다** (online 0.3828 vs 0.3841). causality·
intentionality 를 **어휘 사전만으로** 보강해도 손해가 없다 — 설계문서 §10 이 우려한 *"causal/goal
은 깨끗한 태거가 없다"* 는 **보강 형태에서는 문제가 되지 않는다**(대체 형태에서만 문제).

**③ 🔴 AUC 는 오르지 않았다 — 사전 규약대로 "순위력 향상"이라 부르지 않는다.**
hybrid 의 Δ AUC 는 −0.0036 / −0.0089 로 사실상 평평하거나 미세 하락이다. D-B35 사전 해석 규약의
*"AUC 가 오르면 순위력, 평평하면 임계 맞물림"* 중 **후자**로 읽는다.
⚠️ 다만 실측은 그 이분법에 안 들어가는 **세 번째 경우**다: pooled AUC 는 평평한데 **oracle 개수
matched 는 0.4519 → 0.4769 로 크게 올랐다**(+0.025). 전자는 문서를 합쳐 잰 순위, 후자는 **문서
내** 순위다 ⇒ *문서 내 순위는 좋아지고 문서 간 점수 스케일 정합은 아니었다* 는 해석이 가능하다.
deployable 규칙(otsu·μ+cσ)이 **문서별로** 계산되므로 Score 개선과 앞뒤가 맞는다.
**사전에 이 경우를 적어두지 않았으므로 결론으로 삼지 않고 후속 검증 대상으로 남긴다.**

**④ monkey 가 처음으로 좋아졌다.** 0.2756 → 0.2912/0.2952. 지금까지 모든 구조 개선(M5·M6·구조화
벡터)에서 monkey 는 **반대 방향**이었다(D-B17 이후 일관된 패턴). 태거는 그 패턴을 깬 첫 신호다.
monkey 는 D-B31 에서도 우리 방법이 약했던 문서이며 *"상황모델이 정지한 텍스트"* = 이론의 경계조건
후보였다. **표층 언어 신호(시간표현·인물언급)가 거기서 도움이 된다**는 것은 그 자체로 관찰 가치가
있으나, 1개 문서·3 seed 이므로 **가설로만** 적는다.

**⑤ J_anchor 와 dev-3 가 어긋난다.** hybrid3 은 dev-3 에서 이기고 J_anchor 에서는 −0.0023 이다.
D-B34 에서는 두 지표가 6셀 전부 방향이 일치했으므로, **어긋난 첫 사례**다. 앵커 의사-gold 가
폐기된 t\*=3 규칙에 기대어 순환한다는 지적(부칙 1)과 정합적이다.

## 4. 판정

| 질문 | 답 |
|---|---|
| 태거가 축 공간을 정의하면 더 좋아지는가 | **덧붙이면 예**(hybrid 우세) · **대체하면 아니오**(replace 열세) |
| §4.6 D1 문자 그대로 | **기각** (replace 가 AUC 까지 무너뜨림) |
| causality/intentionality 도 넣어야 하나 | **넣어도 손해 없음**(hybrid 3축 ≈ 5축) |
| 순위력이 올랐나 | **pooled AUC 기준 아니오.** 문서 내 순위(oracle 열)는 올랐으나 사전 미등록 |

**조치:** `configs/m5_default.json` **미변경**(사전 선언대로 — 이번 라운드에서 기본 분절기를 바꾸지
않는다). hybrid 채택 여부는 **별도 결정**이며 codex 위임 대상이다.

**다음 후보:**
- ⬜ hybrid 를 **다중 seed·다중 데이터**로 재확인(현재 dev-3 3편뿐) → 채택하려면 필수
- ⬜ 태거 피처의 **축별 기여 분해**(어느 축의 신호가 이득을 냈나 — 3축 vs 5축이 같다는 건
  causality/intentionality 어휘 사전이 무해할 뿐 기여도 없다는 뜻일 수 있다)
- ⬜ **경계 개수 제어**(여전히 최대 미결 — hybrid 도 160~390개 예측, gold 66)

## 5. 한계 / 검증 미해결 (제거 금지)

1. **dev-3 3편.** pieman 선택압 9회 누적. 절대 Score 인용 금지 — Δ·방향만.
2. **AUC 가 안 올랐다.** 개선이 순위력이 아니라 임계와의 맞물림일 가능성이 크다. 임계 규칙이
   바뀌면 이득이 사라질 수 있다.
3. **otsu 에서는 hybrid3 이 −0.0038 로 진다.** 3규칙 중 1개는 반대 방향이다.
4. **J_anchor 는 반대로 말한다**(위 §3⑤). 두 지표가 어긋난 첫 사례이며 어느 쪽이 옳은지 미해결.
5. **어휘 사전은 영어 전용**이고 손으로 만들었다. 한국어(Tier 3)로 옮길 때 그대로 못 쓴다.
6. 태거 피처가 **표층 단서**(따옴표·물음표 등)를 포함한다. gold 는 안 쓰므로 누출은 아니지만,
   *"상황모델 지표"* 라기보다 **문체 신호**로 작동했을 가능성을 배제하지 못했다 — 축별 기여
   분해로 확인해야 한다.
7. 프로브(축 분리)를 태거 셀에는 **아직 안 돌렸다.**
