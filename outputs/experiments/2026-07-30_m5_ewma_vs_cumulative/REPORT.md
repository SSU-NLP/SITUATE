## 0. 🔒 지위 (실행 전 선언 — 결과 보고 바꾸지 않음)

- **봉인 시험지(신규 3편 *Born a Crime*) 미개봉.**
- **선택셋 = dev-3 하나뿐**(D-B41 §2). 🔴 공시: 서사 작동점을 **보고하는 셋에서** 골랐다. pieman 에 9라운드 선택압 누적 ⇒ **절대값을 성능으로 인용하지 말고 Δ·방향만** 인용한다.
- **DTS 공식 test 3종 = 판독(read-out)**, span 선택에 쓰지 않았다. (D-B39 는 c=1.0 을 공식 test 에서 골랐으나 **D-B41 §2 가 그 관행을 조였다**.)
- **이 표로 `configs/m5_default.json` 을 바꾸지 않는다.** 채택은 별도 사전등록에서.
- ⚠️ DTS 는 전부 **대화**, 본 scope 는 **서사**. 도메인 붕괴는 양방향(D-B31/B32).
- ⚠️ **두 규칙의 비대칭:** `online_nf` 는 현재 샘플을 자기 μ/σ 에 **포함**하고(`hi_ontop_v2.py:198-203`), `ewma` 는 **판정 후 갱신**이라 포함하지 않는다(`:214-218`). ⇒ 차이는 *국소성 + 자기포함* 두 성분의 합이며 본 실험은 둘을 분리하지 못한다.

## 8. 해석

> 🔴 **①은 철회됐다** (상단 정정 배너). 작동점 성분을 통제하지 않은 해석이었다. 아래는 *c=1.0 조건에서 관측된 사실* 로만 읽는다.

**① ~~국소화할수록 나빠진다~~ → 철회.** (c=1.0 조건) dev-3 Δ(EWMA−누적) = span5 **-0.0364** · span20 **-0.0188** · span50 **-0.0137**. span 이 커질수록 손해가 줄어든다. **그러나 이것을 *국소성의 해악* 으로 읽은 것은 오류다** — 같은 c 에서 EWMA 가 경계를 더 많이 뱉었고(160 vs 226/184/167) 진 것은 과예측 벌점 때문이다. 개수를 맞추면 dev-3 에서 **차이가 사라진다**(`REPORT_COUNTMATCHED.md` §2).

**② 이유 = 개수 제어가 더 나빠진다.** dev-3 과분절 배수 = 누적 2.42× → span50 2.53× → span20 2.78× → span5 3.42×. 국소 통계는 점수가 잠깐 높아진 구간에 **임계까지 같이 따라 올라가지 않고** 그 구간 안에서 반복 발화한다. **D-B34 의 최대 미결(경계 개수 제어)이 완화되기는커녕 악화된다.**

**③ 🔴 가장 중요 — EWMA 가 고치려던 문제가 dev-3 에 애초에 없다.** §5 10분위에서 누적 규칙의 예측 밀도는 D1 0.222 → D10 0.162, 선형 기울기 **+0.0009/분위**로 **후반부 감소 추세가 없다**. 즉 *'누적 μ/σ 가 후반에 굳어 둔감해진다'* 는 가정이 **dev-3 에서 성립하지 않는다**. 이는 D-B42 §6 이 GutenQA 에서 실측한 것(1.01배, 효과 없음)과 **같은 결론**이며, 본 실험의 사전 예상과도 일치한다. ⇒ EWMA 는 **존재하지 않는 병에 대한 처방**이었다.

**④ cold-start 는 주원인이 아니다.** §6 에서 dev-3 span50 의 cold-start 오탐률은 0.156 로 누적(0.156)과 **같은데도** Score 는 여전히 -0.0137 진다. ⇒ 손해는 초기화 아티팩트가 아니라 **정상 구간의 국소성**에서 온다. (`RunStat` 식 cold-start 보정을 넣어도 결론이 뒤집힐 가능성은 낮다.)

**⑤ 🔴 도메인이 갈린다 — 서사는 지고 대화는 이긴다.** `ewma-span5` Δ = tiage **+0.0128** · dialseg711 **+0.0310** · superseg **+0.0105** ⇒ 대화 3종 **전부 +**, 서사(dev-3)는 -0.0364 로 **−**. D-B31/B32 가 말한 **양방향 도메인 붕괴**가 임계 규칙 층에서도 그대로 나타난다. 화제 밀도가 국소적으로 변하는 대화에서는 국소 임계가 맞고, 사건 경계가 성긴 서사에서는 안 맞는다.
  🔴 **그러나 이것으로 규칙을 바꾸지 않는다.** DTS 는 사전 선언대로 **판독 지위**이고, 본 프로젝트 scope 는 **서사**다. 대화용 규칙을 따로 두려면 superseg/validation 에서 **별도 사전등록**이 필요하다.

**⑥ M5−M4(분리의 기여)는 규칙을 바꿔도 살아남는다.** dev-3 Δ = cumulative +0.0394 · ewma-span5 +0.0239 · ewma-span20 +0.0282 · ewma-span50 +0.0335 — 네 규칙 전부에서 M5 > M4. **본 논문 주장은 임계 규칙 선택에 의존하지 않는다**(강건성 확인).

**⑦ 부록의 유혹 (⚠️ 결과 아님).** §7 에서 `ewma-span20 c=2.0` 이 dev-3 0.4164, `ewma-span50 c=2.0` 이 0.4180 로 폐기된 고정분위수(0.4191) 수준을 낸다. **이것을 채택 근거로 쓰면 안 된다** — c 는 D-B39 가 평가셋 밖에서 고른 1.0 으로 동결돼 있고, 이 표를 보고 c=2.0 을 고르는 것이 정확히 **selection-on-dev 오염**이다. (다만 *'국소성 + 더 보수적 c'* 조합은 **가설**로 남는다 — 검정하려면 c 를 평가셋 밖에서 다시 뽑는 별도 사전등록이 필요하다.)
