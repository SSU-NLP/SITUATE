# 임계 규칙 — **예측 개수를 맞춘** 비교 (작동점 통제)

> seed [0, 1, 2] · `_per_slot_slot` · c 를 0.0~3.5 (step 0.05) 로 훑어 목표 개수에 맞춤 · 신호·모델 불변

## 왜 이 표가 필요한가 — D-B43 해석 정정

D-B43 은 **c=1.0 고정**으로 비교하고 *"국소성 자체가 해롭다"* 고 해석했다. **그 해석은 과했다.**
- 같은 c=1.0 에서 규칙별 예측 개수가 **제각각**이라(dev-3 160 vs 226/184/167) 비교된 것은 상당 부분 *국소성* 이 아니라 **서로 다른 작동점**이었다.
- 실제로 c=1.5 부터 순서가 **뒤집힌다**(cumulative 0.3687 < ewma20 0.3851 < ewma50 0.3911).
- ⚠️ **AUC 는 네 규칙이 완전히 동일하다** — 신호가 같기 때문이다. 규칙이 바꾸는 것은 **문턱을 어디에 긋느냐** 뿐이므로, 고정 c 비교는 D-M12 가 경고한 **"μ+cσ 임계의 작동점 성분"** 함정에 그대로 빠진다.

🔴 **이 실험은 dev-3 에서 c 를 고르는 것이 아니다.** 맞추는 대상이 *점수* 가 아니라 *개수* 이고, 목표 개수도 **현행 규칙(누적 c=1.0)이 스스로 낸 값**이라 gold 를 쓰지 않는다 ⇒ 오염 아님.

## 5. 한계 (제거 금지)

- 개수 매칭은 **총합** 기준이다. 문서별 개수까지 맞춘 것은 아니다.
- c 격자 0.05 라 목표 개수와 정확히 일치하지 않을 수 있다(표의 실제 개수 병기).
- dev-3 = 연습장 3편. 절대값은 성능이 아니다 — Δ·방향만.
- 상한 포락선(§4)은 **평가셋에서 c 를 고른 값**이라 어떤 채택 근거도 되지 못한다.
- seed [0, 1, 2].
