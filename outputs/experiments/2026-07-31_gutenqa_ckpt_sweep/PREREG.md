## 1. 무엇을 묻는가

M5-FactoredSlot 의 디폴트 체크포인트가 두 번 바뀌었다(W0 → W3 → I2). 상류 dev-3 DTS Score 는
0.3617 → 0.3963 → 0.4053 으로 올랐다. **그 상류 개선이 하류 과제로 전이되는가.**

| 세대 | 조건 | dev-3 | md5 |
|---|---|---|---|
| W0 | pos_weight = clip[(1−p)/p,1,30] | 0.3617 | `b65ca641` |
| W3 | pos_weight 전축 1 (plain BCE, D-B44) | 0.3963 | `1312fffc` |
| I2 | W3 + 의도축 재조작화 | 0.4053 | `72f434e4` |

이 실험이 답하지 **않는** 것: 경계 위치의 기여. 밀도매칭 무작위 대조를 이번엔 돌리지 않으므로
위치 가설은 건드리지 않는다(이미 D-L18 에서 7조건 기각).

## 2. 사전 예측 (귀무가설)

**하류 변화는 0 근처일 것이다.** 근거는 우리 자신의 두 결과다.

1. **위치 기여 7조건이 통제 강화와 함께 0으로 수렴**했다(D-L18). 가장 엄격한 제약디코딩 조건에서
   `m5 − random = −0.08 [−0.36, +0.21]`.
2. **GutenQA 성능의 91%가 평균 청크 단어수로 설명**된다 — `DCG@20 = 0.0221 × 평균단어 + 46.03`,
   r = +0.914 (p = 0.00022), 잔차 RMSE 0.148 (D-B44).

⇒ 체크포인트가 바뀌어도 **밀도가 비슷하면 하류도 비슷할 것**으로 예측한다.
이 예측이 빗나가면(잔차가 유의하게 개선되면) 그것이 발견이다.

## 3. GutenQA — 판정 규칙

**주지표** = DCG@20. **주값 셀** = `cd_adaptive` (제약 디코딩 + 적응임계).
사전등록된 주값이며 **결과를 보고 최고점 셀로 갈아타지 않는다.**

**격자**: 10규칙 × 2체크포인트(I2·W3) = 20셀. W0 20셀은 기존 실측을 그대로 비교 기준으로 쓴다.
`rate0.15` / `adaptive_online_nf_c1` / `ewma5_c1` / `ewma20_c1` / `ewma50_c1` /
`rate0.15_b1` / `adaptive_online_nf_c1_b1` / `ewma20_c1_b1` / `cd_adaptive` / `cd_ewma20`

**동결 항목 — 새 체크포인트에서 재도출하지 않는다.**
- 임계 계수 `c = 1.0` (출처: SuperDialseg 공식 test 36,109 전이)
- 길이 바운드 MIN 70 / MAX 374 (출처: dev20편 gold span p95 · 인코더 512토큰 ÷ 1.366)
- 폐기 분위수 `r = 0.0642`
재도출하면 체크포인트 효과와 바운드 효과가 섞여 어느 쪽인지 말할 수 없게 된다.

### 🔴 핵심 통제 — 회귀선 잔차로만 인정한다

체크포인트 이득은 **원 DCG 상승이 아니라 동결 회귀선 초과 잔차**로 판정한다.

```
잔차(cell) = DCG@20(cell) − (0.0221 × 평균단어(cell) + 46.03)
이득       = 잔차(I2 or W3, cell) − 잔차(W0, cell)
```

회귀 계수 `0.0221 / 46.03` 은 **W0 실측에서 유도된 동결값을 그대로 쓰고 재적합하지 않는다.**
재적합하면 새 데이터에 맞춰 기준선이 따라 움직여 순환이 된다.

원 DCG 만 오른 경우는 "청크가 굵어졌다"와 구분되지 않으므로 **이득으로 인정하지 않는다.**

### 판정 기준

- **체크포인트 효과 인정** = 10규칙 중 **6규칙 이상에서 잔차 이득이 같은 부호(양수)**
- 단일 규칙 결과는 발견이 아니다. 조건을 바꿔 재현되기 전까지는 노이즈 또는 임계 규칙과의 상호작용이다
  (이 프로그램에서 세 번 확인된 규칙, D-L19 철회의 근거)
- 쌍체 부트스트랩 10,000회로 CI 를 낸다. CI 가 0을 포함하면 "구분 안 됨"으로 적는다
- **mpnet 과 ada-002 가 갈리면 양쪽 다 보고**한다. 유리한 인코더를 고르지 않는다

## 4. EM-LLM — 판정 규칙

**arm 3개** (I2, 128샤드 PROCS=1): `m5_i2_c1.0` · `m5_i2_ewma20` · `m5_i2_cd`
d44(W3) 와 **같은 3규칙**이므로 체크포인트 단일변수 비교가 성립한다.

**기준 (D-L15 사전등록을 그대로 이어받는다)**
- `m5_i2 − m5_adaptive_c1.0(W0 51.77) ≥ +0.5` 이면 "체크포인트 품질이 하류로 전이된다"

### 🔴 교란 사전 명시 — 결과를 보기 전에 적는다

입도가 지배 변수이고 **굵을수록 나빴다**(D-L03: `m5@512 − m5@128 = −0.74`).
W0→W3 에서 세그먼트가 11% 길어졌고 점수가 내려갔다.

- I2 가 **낮으면**: 일부는 체크포인트 품질이 아니라 **입도 탓**일 수 있다 → 품질 열세로 단정하지 않는다
- I2 가 **높으면**: 입도 불리를 이긴 것이므로 **더 강한 증거**다

이 해석을 사후에 고르지 않도록 **세그먼트 길이·경계 밀도 통계를 점수 열람 전에 먼저 기록**한다.
